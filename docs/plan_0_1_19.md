# 0.1.19 计划：设置双列减少滚动

状态：已合 main 并公开交付（2026-10-21）。准确候选、公开附件、真实 .18 → .19 更新及同版工具下载通过，证据见[验收记录](validation_0_1_19.md)。前置 [0.1.18](archive/plan_0_1_18.md) 已公开，不替换其附件或标签。需求依据：[设置日常可用 PRD](prd_6_1_1.md) 的 0.1.19 开发调整与 [设计语言摘要](design.md)。

## 1. 用户问题与目标

用户反馈设置窗口纵向滚动不舒服，要求尝试双列减少滚动。**.19 的主线是让默认宽窗完成日常设置不需要滚动**，同时窄工作区仍能访问全部入口；不新增设置项，不改动保存、更新与授权动作契约。

## 3. 实施约束

保持现有设置项、保存反馈、更新与授权动作契约不变；双列只是布局重排，不改变控件语义、来源展示与桌面管理的显式确认路径。继续使用原生控件、`IsDialogMessage` 键盘路由与按窗口 DPI 的测量布局，字体随 DPI 替换释放。宽窄往返不得累积行高或挤出页脚。

## 4. 测试分层与停止条件

| 风险 | 最小验证 | 复用 |
|---|---|---|
| 双列排布错乱或滚动条误现 | 默认宽窗实际截图：无纵向滚动条，各区可见 | 未改的设置项与保存逻辑 |
| 窄窗入口不可达 | 480 × 560 像素窄窗回退单列，必要时滚动可达全部控件 | 既有页脚固定契约 |
| 焦点随尺寸/DPI 变化丢出视口 | 缩窗与 DPI 改变后焦点项可见的定向检查 | 0.1.6 的键盘与焦点规则 |
| 语言/主题组合布局回归 | 中/英 × 明/暗代表组合目视检查，含展开桌面管理 | 未改的主题 tokens |
| 宽窄往返状态污染 | 宽→窄→宽往返恢复双列、行高不累积 | — |

只验证对应布局，构建与格式检查通过即停；不重复发布、UAC、进程管理或更新测试。发布步骤完成后才能标记公开交付。

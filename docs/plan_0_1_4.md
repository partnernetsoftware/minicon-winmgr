# plan_0_1_4 — 0.1.4 版本计划

> 起草：2026-10-14 · 上一版：v0.1.3（已发布）· 状态：✅ R1–R7 已实现；本机验收完成，未覆盖环境逐项列明。
> 主题：**Win+R 运行对话框达到日常可用**。需求唯一来源：[`prd_1_1_1.md`](prd_1_1_1.md)；主索引：[`prd.md`](prd.md)。

## 1. 交付目标

用户能正确运行带参数命令、打开路径/网址；失败留窗可改；重复命令从历史选择；键盘、IME、DPI 和多屏不妨碍输入。0.1.3 的通知区与代码健康作为起点，0.2.0 的任务栏拆分/长跑继续留在原计划；本版只治理运行链条所需改动。

范围按 R1–R7 全部交付。浏览、提权、应用搜索、递归索引、参数补全不在本版。任何范围削减须先更新 PRD 与本计划，不能把未交付项标为完成。

重点风险：从 bool 启动结果扩展到可展示错误时保住旧调用行为；IME 候选窗不能触发失焦隐藏；原始历史文本和解析后的目标不能混用；超时并不等于底层 IO 取消。S0先解决机制可行性，后续才落地 UI，不将草案当作已实现能力。

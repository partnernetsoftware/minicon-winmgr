# plan_0_1_4 — 0.1.4 版本计划

> 起草：2026-10-14 · 上一版：v0.1.3（已发布）· 状态：⬜ 计划，尚未开始实现。
> 主题：**Win+R 运行对话框达到日常可用**。需求唯一来源：[`prd_1_1_1.md`](prd_1_1_1.md)；主索引：[`prd.md`](prd.md)。

## 1. 交付目标

用户能正确运行带参数命令、打开路径/网址；失败留窗可改；重复命令从历史选择；键盘、IME、DPI 和多屏不妨碍输入。0.1.3 的通知区与代码健康作为起点，0.2.0 的任务栏拆分/长跑继续留在原计划；本版只治理运行链条所需改动。

范围按 R1–R7 全部交付。浏览、提权、应用搜索、递归索引、参数补全不在本版。任何范围削减须先更新 PRD 与本计划，不能把未交付项标为完成。

## 2. 切片与依赖

| 切片 | 引用需求 / 工作 | 依赖 | 完成条件 | 状态 |
|------|-----------------|------|----------|------|
| S0 基线与接口设计 | R3/R7；核对 Windows features、消息泵/IME 路径、启动错误来源；确定结构化启动请求、结果、相对目录和异步投递生命周期 | 无 | 留下解析规则和接口草案；确认旧 `shell_launch` 调用者兼容。只用语义化 Windows feature，不以 `link!` 绕过约定 | ⬜ |
| S1 正确启动与失败闭环 | R3/R4；目标/参数解析、环境变量、明确工作目录、Explorer保护、错误分类、去重复提交 | S0 | V1–V4、V11通过；旧菜单/快速启动/launcher 启动路径无回归 | ⬜ |
| S2 可用的对话框 | R1/R2/R6；中文布局、原生编辑控件、键盘/IME、草稿/重复呼出、失焦、DPI与多屏 | S0；提交部分依赖S1 | V5–V7、V10通过，错误文本/候选区域布局可扩展 | ⬜ |
| S3 历史与候选 | R5/R7；30条历史、清空、过滤、目标路径一级建议、有界查询/过期结果丢弃 | S1成功结果、S2候选与焦点 | V8–V9、V12通过；坏文件/慢盘不阻塞输入 | ⬜ |
| S4 整体验收与文档回写 | R1–R7；自动检查与真实GUI流程；采样资源/响应；记录未能验证环境 | S1–S3 | 验收矩阵有证据，PRD状态据实更新，版本号/CHANGELOG仅在交付时更新 | ⬜ |

重点风险：从 bool 启动结果扩展到可展示错误时保住旧调用行为；IME 候选窗不能触发失焦隐藏；原始历史文本和解析后的目标不能混用；超时并不等于底层 IO 取消。S0先解决机制可行性，后续才落地 UI，不将草案当作已实现能力。

# 0.1.14 开发验收：显示桌面

状态：新增按钮已实现并完成本地验证，尚未公开发布。2026-10-19。当前公开版仍为 [v0.1.13](https://github.com/partnernetsoftware/minicon-winmgr/releases/tag/v0.1.13)。范围见[版本计划](plan_0_1_14.md)。

- 单击时钟旁显示器图标，异步请求当前虚拟桌面应用窗口最小化；包含设置窗口，保留桌面、任务栏和工具窗。重复点击继续最小化。
- 横向为时钟右侧按钮，竖向为底部时钟旁按钮；竖向日期和时间分两行。中英文悬停提示沿用统一语言与明暗主题。
- 普通单元测试 331 项通过、13 项独立实验忽略；fmt 与严格 Clippy 通过。
- 新增私有桌面原生 fixture：使用自有应用、工具窗、桌面表面和任务栏 HWND，通过真实鼠标消息处理路径触发最小化，四边 × 明暗均通过；验证两应用均最小化、桌面及工具窗保留、重复点击不还原。fixture 运行测试二进制，不混称为公开 exe 的人工走查；不切换到私有桌面、不最小化用户正在使用的窗口。
- 本地优化开发 exe 完成既有外观回归：明暗主题、四边停靠、设置与详情、自动主题、40 次主题/位置切换及工作区恢复，27 项通过。人工复核横向与竖向截图，按钮与时钟分离、日期时间可读；结束后原实例路径、文件摘要、工作区和 Shell 设置恢复。
- 早期布局测试因按钮新增 28px 固定空间而超出原四图标预算；已调整样例宽度以保留原测试条件，再跑完整单元与严格检查通过。早期 fixture 编译错误已修正，不把失败轮次当作通过。

私有桌面检查入口为 `scripts/isolated_tray_probe.py --test-exe <本地测试二进制> --test show-desktop`。原始日志、截图及恢复报告保留在忽略目录，不上传桌面内容。

目前没有验证物理多屏、特殊账户策略或管理员窗口的跨权限最小化；Windows 或应用拒绝最小化时不提权、不阻塞任务栏。原 Run 交互讨论与管理员复选框未在本次实现，未发布 0.1.14 Release。

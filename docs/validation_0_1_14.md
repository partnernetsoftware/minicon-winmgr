## Run R8 开发阶段

原生复选框加入现有 Run，提交时捕获命令、权限、窗口及选区；原有单个有界 worker 根据选择调用统一启动模块的普通或系统 UAC 分支。重新呼出复位未选，重复唤起保持当前选择；提交中禁用权限切换。授权期间的安全桌面失焦不作废请求，显式关闭仍可隐藏；旧结果不覆盖新的草稿、错误提示或权限选择，已被系统接受的旧命令仅记录其自己的历史。

隐藏原生控件测试覆盖快照、取消选区、重复提交、重开复位及过期成功/失败回复，不触发 UAC。初次控件 fixture 使用隐藏父窗口的 BM_CLICK 无法切换，已改为设置原生选中状态来测生命周期；实际键盘切换单独由真实界面验证。一次普通单元矩阵与实机测试同时争用前台导致既有焦点用例失败，原始记录保留，后续串行执行；不得把该轮当作矩阵通过证据。

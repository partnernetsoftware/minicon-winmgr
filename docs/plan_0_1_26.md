# 0.1.26 计划：设置强调色与紧凑布局

状态：已公开（2026-10-28，v0.1.26 Latest，tag v0.1.26）。验收证据见 [validation_0_1_26.md](validation_0_1_26.md)。以下“采样证据”一节为顺延的讨论稿，未纳入本版。需求依据：[工具 PRD §7](prd_7_1.md#7-下一阶段树式任务管理与持续分析)的依赖顺序——树与对象、人工笔记/状态、agent 同契约读写均已在 [0.1.18](archive/plan_0_1_18.md) 公开，下一环是**有证据的异常辅助**。

## 1. 用户问题与目标

.18 的异常/关注标识完全依赖人或 agent 的主动判断，笔记"依据"栏只能手工转述观察。当用户或 agent 想回答"这个任务最近是不是异常"时，没有可直接引用的客观采样证据，也没有附带判定规则的提示。

.22 的目标：对选中任务提供**有界、可解释的资源采样证据**，让人和 agent 在同一契约下引用它作笔记依据；在证据之上提供**最小集的可解释提示**——提示必须展示采样数据与判定规则，由人确认、忽略或撤销，不自动标异常，更不自动处置。

## 2. 任务树（待确认，可裁剪）

```text
.22 采样证据主线
├── [ ] 选中任务的有界采样：CPU、私有内存、句柄数按周期采集；窗口隐藏/关闭即停，不常驻
├── [ ] 采样摘要展示来源、周期与区间；不可得指标明确标注，不伪造零值
├── [ ] 笔记引用：采样摘要可一键填入依据栏，注明采样区间；人工与 agent 共用同一结构
├── [ ] agent 接口：`--notes-json` 增加读取当前采样摘要的结构化字段，不新增权限
└── 可解释提示（最小集，范围待讨论）
    ├── [ ] 持续超阈值（如 CPU/内存）时提示，附实际样本与规则文本
    └── [ ] 提示支持确认 / 忽略 / 撤销并记入笔记历史；不自动设置异常状态
```

依赖：采样与摘要 → 笔记引用 → agent 字段 → 提示。提示一档如经讨论裁剪，前三项仍构成可交付的最小版本。

## 3. 实施约束

- 采样只针对用户/agent 选中的任务，异步、有界、可停；不给 Winmgr 外壳增加常驻采样负担，空闲与大量进程场景的开销需有证据。
- 不内置模型服务；提示阈值是可展示、可解释的规则，不称为恶意检测。异常标识仍由人或 agent 主动确认，不自动结束进程、提权或阻断网络。
- 进程网络速率继续按 [.17 递延](archive/plan_0_1_17.md)单独立项，不混入本版采样指标。
- 命令行、端点等敏感内容不自动写入采样证据或笔记；证据遵守现有本地存储边界，不上传。
- 采样对象沿用 .18 的身份规则（PID + 创建时间 / 应用路径），不跨 PID 生命周期错误归因。

## 4. 测试分层与停止条件（草案）

| 风险 | 最小验证 | 复用 |
|---|---|---|
| 采样跨 PID/账户错误归因 | 身份校验与 PID 复用定向单元 | .18 对象模型测试 |
| 采样不停或开销失控 | 隐藏/关闭停止、空闲与多进程场景资源证据 | 既有 metrics 采样框架 |
| 证据被当作判定 | 提示文案含规则与样本；确认/忽略/撤销记入历史的组件与实际路径 | .18 笔记契约 |
| agent 接口破坏兼容 | 旧请求不变语义回归；新字段正反例 | task_analysis 契约测试 |
| 发布错配 | 准确候选、公开更新及工具下载 | 既有发布闭环 |

实现未动的权限、更新与外壳逻辑不重复对应矩阵。发布步骤完成后才能标记公开交付。

## 5. 备选与不做

- **任务聚合**（子树聚合资源值、注明范围避免重复计数）：与采样同域，若本版范围过大则另行拆分，不默认捆绑。
- **Sysmgr 只读概览**：按[路线 §2](roadmap_0_1.md#2-sysmgr-的下一步)先查证指标来源、权限与开销，不在 .22 启动。
- 自动处置、常驻监控告警、跨账户证据同步：不做。

## 桌面设置对话框 UI/UX（0.1.26 顺带）

0.1.25 的桌面设置对话框功能正常，但界面与设置面板的风格不统一（默认 GUI 字体、固定控件布局、没有主题适配）。0.1.26 顺带设计并实现：

- [x] 与设置面板统一的视觉语言：0.1.27 起对话框使用设置面板的消息字体、主题背景与标签颜色、主题绘制的下拉框，暗色标题栏。卡片式分组框有意不用（对话框内容少，平铺更紧凑）。
- [~] DPI：对话框按所在窗口的 DPI 布局，WM_DPICHANGED 时重建控件与字体并保留选择（0.1.28）；150% 的重排由私有桌面测试经 WM_DPICHANGED 模拟验证。未完成：真实 150% 缩放显示器的目视确认。需要用户把本机显示缩放设为 150% 后检查（或授权由开发代理临时修改并注销，这会中断当前桌面）。在此之前本项保持 [~]。
- [-] 颜色与图片的即时预览：顺延。色块与缩略图需要 owner-draw 与受控的解码，本版不引入。
- [x] 键盘与可访问性：Tab 顺序、默认按钮（确定）、取消（Esc）由 IsDialogMessage 处理；强调色入口为原生按钮。
- [~] 截图审阅：对话框与设置面板的中英文、浅色与深色已审阅；150% 的对话框截图（模拟 DPI 变化）已审阅。未完成：真实 150% 显示器的目视确认，需用户完成，本项保持 [~]。

## 0.1.26 范围设计（待确认）

0.1.26 的定位：收尾与体验。先把已经发现的缺口补齐，再选一个低风险的功能，不引入新的常驻资源。

### A. 收尾（必做）

- 桌面设置对话框 UI/UX（见上文）。
- [x] 更正文档：0.1.25 对话框已支持清除（颜色与图片都设为未设置即隐藏桌面），`winmgr.cnf` 手改不再是唯一途径。PRD N7、0.1.23/0.1.25 验收与发布说明中的“清除只能改配置”需要删改。
- [x] 设置层测试稳定性：`native_focus_and_escape…` 改为对面板子窗口投递 Escape，面板因失焦隐藏时先重新打开；本机连续三次通过。

### B. 功能（选一，推荐第一项）

1. **统一拾色器**（PRD 1.1 中的“主题拾色器”仍是未做项）：设置面板的主题色与桌面颜色共用同一套对话框与色板，顺带统一 UI/UX。复用 0.1.25 的对话框，改动小，风险低。
2. 电源与输入法状态（FUT-04）：状态来源与交互需先定义，属于较大范围，建议下一版。
3. 拖拽整理分类（PRD 1.1 未做项）：涉及任务栏拖放与配置写回，风险中等。

### C. 不纳入 0.1.26（需要你决定或外部条件）

- 更新下载的国内可达性（PRD 1.1.3 的 D1 镜像主机、D3 签名私钥）：必须由你决定，见 `prd_1_1_3.md` §6。
- 0.1.20 的真实 mstsc 全屏工作流确认：仍待你在真机上确认。
- 小时级稳定性（FUT-02）与物理多屏、混合 DPI（FUT-01）：需要真实设备与长时间运行，不是开发任务。

### 待你确认

- 0.1.26 是否采用“A 收尾 + B1 统一拾色器”，还是换成其他 B 项。
- 原来的采样证据讨论稿（任务分析辅助）是否顺延到 0.1.27，或搁置。

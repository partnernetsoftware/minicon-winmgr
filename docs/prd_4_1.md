# prd_4_1 — 设计语言 · 效率条

> 索引：4.1 · 树路径：`设计语言` · 上位文档：[`prd.md`](prd.md)
> 原始独立文档 `ui-ux.md` 已并入本文。实现：[`src/taskbar.rs`](../src/taskbar.rs)、主题 [`src/config.rs`](../src/config.rs)。

定位：不是壁纸/装饰系统，而是一条"**看一眼就知道系统在干什么、点一下就能切过去**"的极简任务栏。

## 1. 设计原则
1. **内容优先，chrome 最小** — 无大图标、无开始按钮装饰、无渐变阴影。任务按钮的 16px 应用图标是**身份锚点**，不是装饰：宽度恒定，让"哪个应用"先于"哪个窗口"被识别。
2. **一屏一焦点** — 同一时刻只有一个"当前窗口"高亮；hover 只给中性反馈。
3. **静默美学** — 深色、低对比背景；颜色只在 hover / active 作信号。
4. **效率第一** — 36px 单行、点击即切换。**图标定身份、标题定区分**：图标是恒定宽度的锚点，标题承担同应用多窗口之间的分辨。
5. **可观测内建、噪声最小** — 右侧只读区**只放时钟**（任务数不入 UI：任务按钮本身已表达数量，重复计数是噪声）。

## 2. 视觉规范（design tokens）
| Token | 值 | 用途 |
|-------|----|------|
| `bar.height` | 36 px | 任务栏高度 |
| `bar.padding` | 10 px | 左右内边距 |
| `bar.gap` | 4 px | 元素间距 |
| `rightZone` | 142 px | 右侧只读区（`CLOCK_W(132) + PAD`）——只预留时钟 |
| `button.min` / `max` | 120 / 200 px | 任务按钮宽度夹取 |
| `icon.slot` | 16 px | 任务按钮内的应用图标尺寸 |
| `icon.pad` / `icon.gap` | 8 / 7 px | 图标左内边距 / 图标与标题间距 |
| `font` | Segoe UI 12px | 常规；激活态加粗 |

**色板（深色 / `COLORREF 0x00BBGGRR`）**
| 名称 | RGB | COLORREF | 用途 |
|------|-----|----------|------|
| `bg` | 27,27,31 | `0x001F1B1B` | 栏背景 |
| `surface` | 38,38,44 | `0x002C2626` | 按钮静止态 |
| `surfaceHover` | 51,51,59 | `0x003B3333` | 按钮 hover |
| `accent` | 76,139,245 | `0x00F58B4C` | 激活窗口 / 品牌点 / 设置与列表图标 |
| `text` | 230,230,230 | `0x00E6E6E6` | 主文字 |
| `textMuted` | 154,154,162 | `0x00A29A9A` | 次要文字（时钟） |

> 主题可由 `config` 覆盖（`minicon.conf` 或 `MINICON_CONFIG`），默认值即上表。

## 3. 布局（anatomy）
```text
┌────────────────────────────────────────────────────────────────────────────┐
│ ⚙ ●  [▣][▣] ≡  [▤ 编辑器 ] [▤ 终端 · bash ] [▤ 浏览器 ]     26-10-13 09:29 │
└────────────────────────────────────────────────────────────────────────────┘
  ↑  ↑    ↑     ↑              ↑     ↑                              ↑
  设置 品牌  快速启动 列表按钮 图标  任务按钮(图标+标题,激活态 accent 左条) 右侧只读:时钟
```
- **设置按钮**（最左）：三条滑杆图标 → `settings_ui`。
- **品牌点**：6px accent 圆点（菜单按钮）→ `start_menu`。
- **快速启动**：`quick_launch` 钉住的方块（最多 5）。
- **列表按钮**：≡ 图标 → `task_list` 弹出全部窗口。
- **任务按钮**：宽 `clamp(可用宽/任务数, 120, 200)`；左侧 16px 应用图标（`window_icon`：`WM_GETICON` → 窗口类图标，带 50ms 超时与 per-HWND 缓存），右侧标题 `DT_END_ELLIPSIS`。
- **溢出规则（重要）**：右侧只读区（时钟）**永不被覆盖**。当 `n` 个按钮在最小宽 `120` 下放不下时，
  显示尽可能多的完整按钮 + 一个 **溢出按钮 `»`**（`OVERFLOW_W=44`），点它弹出未显示窗口的列表（`hidden_from..`）。
  即"窗口很多"时自适应为 `N 可见 + » 折叠`，而不是把按钮挤进时钟区。
  默认**每窗口一按钮**（对齐 Alt+Tab 心智）；`MINICON_GROUP_TASKS=1` 切回按 pid 分组，分组标签追加 `(+N)`。
- **右侧只读区**：仅 `yy-mm-dd HH:MM`（muted）；其左侧是通知图标条（无图标则不占位）。
  时钟由 **5s 定时器**（`CLOCK_TIMER_ID`）重绘，保证分钟准点（心跳 30s 太粗）。

## 4. 交互
| 事件 | 行为 |
|------|------|
| hover 按钮 | 填充 `surfaceHover` |
| 离开栏 | 清除 hover（`TrackMouseEvent` + `WM_MOUSELEAVE`） |
| 左键点任务 | 激活窗口（`win_util::force_foreground`，最小化先 `SW_RESTORE`） |
| 左键点任务(组) | 激活组内首个窗口 |
| 右键点任务 | 窗口菜单（还原/最小化/最大化/关闭） |
| 左键点设置 | `settings_ui::toggle` |
| 左键点品牌点 | `start_menu::toggle` |
| 左键点列表 | `task_list::popup` 全部分组窗口 |
| 左键点溢出 `»` | `task_list::popup` **未显示**的窗口（`hidden_from..`） |
| 左键点快速启动 | `quick_launch::launch_path` |
| **双击时钟** | 打开系统日期/时间设置（`ShellExecuteW` → `control.exe timedate.cpl`，与系统托盘时钟双击一致） |
| 心跳 / **窗口事件** / 鼠标进入 | 重新枚举任务并重绘（保留 hover/键盘光标）。窗口创建/销毁/显示/隐藏/前台切换经 `window_events` 去抖 120ms 立即刷新，不等心跳 |
| 悬停任务 ~350ms | 弹缩略图预览（**opt-in** `MINICON_HOVER_PREVIEW=1`） |
| `Alt+`` | 唤出任务栏并进入键盘导航（光标落首个任务） |
| `←` / `→` | 移动键盘光标（accent 描边），环绕 |
| `Enter` | 切换到选中任务并退出导航 |
| `Esc` / 失焦 | 取消导航 |

## 5. 取向对照
| 维度 | 典型桌面外壳 | minicon-winmgr |
|------|--------------|----------------|
| 取向 | 桌面环境（壁纸、图标、动态桌面） | **效率条**：只做窗口切换 + 状态 |
| 视觉 | 大图标 + 分类堆叠 | **16px 图标锚点 + 标题**、更低矮 |
| 差异化 | — | 会话可观测（WTS）+ 受控外壳切换内建 |

## 6. 外观细节
- 圆角 / 亚克力见 `src/dwm.rs`：圆角默认、亚克力 opt-in（`MINICON_ACRYLIC=1`），不支持则降级。
- 窗口类统一 `hCursor = IDC_ARROW`，避免悬停出现"忙"光标。
- 当前色板/右区宽度会随需求调整（用户曾要求去掉"N 任务"计数、时钟改 `yy-mm-dd HH:MM`）——以 `src/taskbar.rs` 常量为准。

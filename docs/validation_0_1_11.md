## 修复、失败与验收条件

四项英文错误文案断言在独立子进程明确选择英文，避免共享全局语言污染，未放宽断言。HTTP fixture 的 Windows accepted socket 显式切回有超时的阻塞 I/O，保留取消/寿命断言；专项五次和全部优化单元通过后重新生产上述候选。

桌面探针也修正了实际前提：侧栏超限目标保持在屏内；独立拖动按系统双击时限隔开，并等待真实捕获/宽度，避免 CS_DBLCLKS 将第二次按下解释为双击；Run 和预览先取得自有窗口前台权，再发送真实键盘/鼠标；通知刷新后检查当前按钮与焦点，避免比较旧 HWND。未用窗口消息冒充真实 hover。这些探针改动不改变候选产品源码。

早期完整层和复核中曾出现 socket 模式、屏外/快速鼠标输入、无关前台应用、失效 HWND 及 RDP 会话 Disc/Access denied 失败，原始失败日志保留。通过范围依据同一准确候选的可靠分段证据，不宣称早期失败本轮通过，也不要求反复重跑已确认的前半静态/组件检查。

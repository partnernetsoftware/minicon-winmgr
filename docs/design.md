# 当前界面规范

适用：0.1.10 已发布界面及 0.1.11 工作树的增量调整。真实界面以[中英文 README 截图](../readme.md)、原生实现和[发布验收](validation.md)交叉核对；截图仍来自 0.1.10，不能替代新版验收。早期草图与配色探索见[归档](archive/README.md)。0.1.12 尚为[讨论稿](plan_0_1_12.md)。

- 风格：工业面板的清晰结构、暖色纸张和棕色强调、细边框、克制装饰。沿用原生控件的键盘与 UIA 语义；普通按钮仅重绘表面，不另造交互体系。
- 语言与外观：默认 English，支持中文即时切换并保存；Light / Dark / Auto，自动主题跟随 Windows 应用主题；任务栏可在四边停靠。
- 设置：单页卡片，不设侧栏。外观与位置、任务与窗口、版本操作三个紧凑区；配置与关于和折叠的桌面管理置于其后；保存状态和关闭按钮固定在底部。
- 默认窗口约 640 × 634 DIP，限制在工作区内。窄窗允许选项换行和滚动，焦点项保持可见；宽窄往返不能累积行高或挤出页脚。
- 文案只说明用户能做什么及何时生效。主界面不显示环境变量名、API 地址或配置来源；被启动配置固定的选项显示简短固定提示。完整技术来源和更新错误保留在配置与关于及日志。
- 版本区：Check / Update / Restart，随状态启用；打开设置不联网。下载与重启分开，未保存设置时禁用重启；不向用户展示内部助手路径和事务步骤。
- Run：两行原生建议展示名称/命令与来源，键盘选中后按钮为 Use，采用后为 Run；0.1.11 工作树上下键同步预览文本，Esc 恢复草稿与选区，继续输入则编辑当前文本；采用不会执行，失败保留输入。用户反馈仍需打磨，不把这一版视为 UX 定稿。
- 时钟：0.1.11 工作树采用 `Www yyyy-mm-dd HH:MM`，英文三字母星期与 24 小时时间，横向预留宽度与命中区域一致。
- 稳定性：耗时网络、下载、校验和替换在 worker/助手；窗口归消息线程。普通启动不申请 UAC，自身已提升时按同用户同会话降权规则处理。

颜色数值以 `src/config.rs` 的调色板为实现依据，几何与绘制见 `settings_panel`、`run_dialog`、`dock`、`taskbar`。新设计修改前先更新对应版本计划；开发按[测试层](testing.md)选择，发布前执行完整 release 层。

# 0.1.23 计划：替换模式图片壁纸

状态：计划（未开工，版本号仍为 0.1.22）。需求回写见 [prd_1_1_2.md](prd_1_1_2.md) §N7。上一版 [0.1.22](validation_0_1_22.md) 已公开。采样证据讨论稿顺延为 [0.1.24](plan_0_1_24.md)。

## 1. 目标

替换模式下，在“桌面设置”中可以选择一张图片作为桌面背景，常驻内存增加接近零。内存方案依据见 PRD §N7 与资料调研（见 PRD §N7）：不依赖 Explorer，不常驻整屏位图，不引入 GPU 设备。

## 2. 任务树

```text
0.1.23 图片壁纸
├── [ ] 原型（先于正式实现）
│   ├── [ ] 分段解码绘制：WIC 解码到屏幕尺寸，每次约 32 行复制到小缓冲，StretchDIBits 绘制
│   ├── [ ] 实测峰值内存（进程私有字节与工作集变化）：1920×1080、3840×2160 各一张
│   ├── [ ] 实测单次绘制耗时，确定大图上限与绘制时机
│   └── [ ] 结论回写 PRD §N7（阈值与数字）
├── [ ] 配置键 desktop.wallpaper（绝对路径，空值清除），单测覆盖解析与往返
├── [ ] 替换模式“桌面设置”：先选图片（打开文件对话框），失败或取消不改配置
├── [ ] 绘制：图片优先，其次纯色；文件缺失、损坏、格式不支持或超过上限时回退，并记录日志
├── [ ] 铺满并居中裁剪，保持比例
├── [ ] 单测：配置解析、回退优先级、大图上限判定、分段计算（覆盖边界行）
├── [ ] 私有桌面测试：选图后像素与样图平均色一致；移除文件后回退纯色
├── [ ] 候选构建与层回归（全屏让位、设置）
├── [ ] 验收记录、发布说明、标签与草稿比对、公开、真实更新探针
└── [ ] 文档收尾（归档 0.1.22 计划、公开版指针）
```

## 3. 验收门槛

- 峰值内存：原型实测值写入验收记录；若超过约 4 MiB，需先说明原因再进入实现。
- 单次绘制耗时：1080p 与 4K 各一次，记录数值；超过上限的图片回退纯色，不阻塞消息线程过久。
- 与 0.1.22 纯色路径相比，不增加其他常驻资源。

## 4. 不做

- Progman/WorkerW 技巧、系统壁纸接口的替代绘制（替换模式下没有宿主绘制，无效）。
- Direct2D/D3D 显存方案（设备初始化的常驻成本未知，留作备选）。
- 多种拉伸、平铺、幻灯片、按显示器不同图片。
- 桌面图标与右键菜单。

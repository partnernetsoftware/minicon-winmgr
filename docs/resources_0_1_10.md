公开证据只保留脱敏 Markdown。实验原始报告、路径、截图留在本地忽略目录；公开曲线和摘要须有场景、构建、时长及覆盖限制。

诊断数据由独立窗口状态持有，开始时分配最多 5762 点的数组（当前 64 位布局约 0.53 MiB）；停止、关闭或上限后释放，保留固定字段摘要。窗口字体在 DPI 更新/销毁时释放，两个定时器分别仅用于正在记录和保存状态轮询。导出线程实际保存时才创建，最多一个任务；关闭诊断窗口停止采样，程序退出通知导出线程取消，原生文件 I/O 无法保证被强制中断，因此 UI 不等待该线程。排序摘要的临时数组有相同样本上限；统计开销和线程成本仍须纳入整应用对照。数据容量/停止释放、慢写入拒绝并发任务、替换失败保留原文件均有专项验证。

日志字段保护在格式化前拒绝文本/Debug/Display/Error 值，因此不会为被屏蔽的路径或错误链先构造完整字符串。两个输出共用规则；事件仍受 16 KiB 格式化预算。开发期 AST 检查约束静态文案，syn 仅为 dev-dependency，不进入正常应用的运行依赖。panic hook 不调用会打印私有载荷和回溯的默认输出 hook；此调整不改变 unwind/abort 策略。

# 0.1.10 资源所有权审计（开发中）

范围与门槛见[版本计划](plan_0_1_10.md)。下表区分已修改、已验证和待解决；不以资源安全审计代替长期实测。

| 对象 | 所有者与释放路径 | 当前上限 / 证据 | 状态 |
|---|---|---|---|
| 日志队列 | NonBlocking worker，退出由 WorkerGuard 交接 | 默认 128,000 改为 512 槽；饱和丢弃，阻塞 sink 测试通过；独立进程两种容量各测三次，debug/release 均测得约 3.92 MiB 私有提交差值 | 已改，消息字节及磁盘保留仍待有界化 |
| 预览 | hover_preview 拥有一个 DWM 关系；换目标、隐藏、销毁和配置失败释放 | 最大一个；不再缓存截图位图；停滞源窗口的 100 次注册/释放通过 | 已改，真实 hover 与关闭/最小化场景待验 |
| 路径图标 | OwnedIcon 最后一个 Arc 引用释放时 DestroyIcon；缓存、pin、paint snapshot 各自持有引用 | 缓存 64 项 / 256 KiB 路径键；正常 pin 最多 8 项；native GetIconInfo 验证清缓存后快照仍有效、最后引用释放后句柄失效 | 已改；键字节上限不冒充 Windows 图像内部字节数 |
| 窗口图标 | 借用目标窗口/类的 HICON，不 DestroyIcon；每次刷新清除映射防 HWND 复用 | 与本轮窗口数相关；每次 WM_GETICON 有 50ms 限制，最多三个查询 | 借用归属明确；累计刷新时间预算待处理 |
| 更新清单 | helper worker 局部 Vec；解析结束释放 | 读取最多 16 KiB + 1 探测字节；超长流测试验证未先读 64 MiB | 已改 |
| exe 下载与校验 | 下载/助手 worker 局部 Vec，网络句柄 Drop；暂存目录由事务持有 | 64 MiB 响应上限；可能同时持有旧/新 exe 和哈希输入 | 仍需流式写入/校验与失败峰值采样 |
| Run 查询 | 固定 worker、单槽请求、最新 pending 与 generation；隐藏后丢弃过期回复 | 候选 20，历史 30；历史文件读取已有 1 MiB 上限；动作队列 32 加去重 Clear | 已有数量限制；字节归因、慢路径退出及缓存指标待验证 |
| 应用发现 | 首次裸名称查询建立索引，worker 持有 | 200ms 检查预算、4096 目录项、深度 12、忽略 symlink 和远程盘 | 原生文件 I/O 阻塞不受检查点预算强制打断；待故障层 |
| 快捷启动文件 | quick_launch 最多读取 1 MiB + 1 字节，解析到 8 个 pin 即停止 | 同目录唯一临时文件、写完刷新并检查外部修改后替换；读取错误禁止当空列表覆盖 | 已改；超长、非法编码、注入失败、外部修改与真实文件占用验证；原生文件 I/O 延迟仍待隔离 |
| 侧边拖宽 | 一个临时 SideDrag 和 16ms timer；结束、取消或销毁撤销 | 拖动不写偏好或工作区状态文件；提交一次异步保存；逻辑宽度与每屏像素边界单测通过 | 当前物理环境的拖动、取消、工作区更新/退出恢复与重启已验；混合 DPI 多屏仍待验 |
| 设置字体/主题画刷 | 对应窗口/主题模块持有；DPI/主题替换释放旧对象 | 现有短轮次回归，需继续采样 GDI/USER 走势 | 尚不能据此证明长时间无增长 |

公开证据只保留脱敏 Markdown。实验原始报告、路径、截图留在本地忽略目录；公开曲线和摘要须有场景、构建、时长及覆盖限制。

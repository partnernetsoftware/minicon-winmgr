状态：[v0.1.11 已公开发布](https://github.com/partnernetsoftware/minicon-winmgr/releases/tag/v0.1.11)，正式发布结果见[验收记录](validation_0_1_11.md)。核对日期：2026-10-18。上一公开版的发布与验收事实保留在 [0.1.10 计划](archive/plan_0_1_10.md)和[验收记录](validation_0_1_10.md)。

## 本版范围

| 项目 | 行为与状态 |
|---|---|
| 日期时间 | 统一显示英文三字母星期、四位年份、补零日期和 24 小时时间：`Www yyyy-mm-dd HH:MM`，例如 `Sat 2026-10-17 18:30`。横向时钟预留区域加宽；侧栏继续单行居中。 |
| Run 候选预览 | 上下键切换候选时同步更新输入框、光标置末尾，保持候选列表和输入焦点；预览不重新查询。Esc/收起/关闭撤销未采纳预览并恢复原草稿与选区，继续编辑则以当前候选文本重新匹配。Enter 先采纳、再次 Enter 执行；IME 组合期间仍由原生输入优先处理。详见 [Run 规格](prd_1_1_1.md)。 |
| 管理员启动 | 初始化配置、单实例和界面之前判断权限。管理员入口必须以同用户、同会话普通权限重新调用自身，保留参数和环境；挂起创建后校验令牌，恢复运行并等待就绪，原进程随后退出。任一步失败报错退出，禁止继续运行管理员外壳。 |
| 普通令牌 | 使用关联令牌或同用户、同会话普通进程的主令牌；拒绝受限 Full 令牌。不再将备用查找截断在前 64 个同会话进程。 |
| 外壳身份 | 用户登录 Shell 指向本产品另一份构建时仍识别为本产品，允许正常初始化通知宿主；已有其他通知宿主时保留原共存规则。 |
| 日志隔离 | 默认路径按账户分目录，显式日志目录配置继续按指定路径使用。 |
| 版本身份 | Cargo 包、锁文件及嵌入清单同步为 0.1.11；设置标题和更新比较继续读取包版本。 |

本轮用户已反馈重新进入后通知图标栏恢复。该反馈不替代完整管理员启动、令牌与故障环境矩阵的验收。未对通知宿主增加跨权限消息放行。

# 0.1.13 — Standard-user startup fix

Windows x64.

- Fixed administrator startup failing with “Unable to start as standard user.” The fallback now enumerates the actual process buffer instead of the Vec header, allowing it to find a verified ordinary token in the same account and session.
- Configuration details now show the running executable path alongside the compiled version and privilege status. Updates preserve the installation path and filename, so an older version number in a filename does not identify the installed version.
- Retained same-account/session checks, ordinary-token verification and startup readiness requirements. Token duplication failures retain a numeric error code in diagnostic logs.

From 0.1.12, use **Check → Update → Restart**. This patch does not rename your executable or change sign-in shell registration. See the [acceptance record](https://github.com/partnernetsoftware/minicon-winmgr/blob/main/docs/validation_0_1_13.md) for verification and coverage limits.

# 0.1.13 — 修复管理员入口启动

Windows x64。

- 修复管理员启动时出现“无法以普通用户身份启动”的问题：普通令牌备用路径此前错误地按 Vec 容器大小枚举进程，现改为实际缓冲区大小，寻找同账户、同会话的真实普通令牌。
- 配置详情显示实际程序路径、编译版本和权限状态。更新保留安装路径及文件名，文件名中的旧版本号不代表当前程序版本。
- 保留账户、会话、普通权限和启动就绪检查；令牌复制失败记录数值错误码，便于定位问题。

0.1.12 可“检查更新 → 更新 → 重启”。本补丁不会自动改名程序或修改登录外壳登记。

# v0.1.21

- 时钟通知面板新增“桌面设置 / Desktop settings”按钮。伴随模式（Explorer 仍是外壳）下打开 Windows 个性化“背景”页，壁纸与颜色由系统处理。
- 替换模式（Minicon 是外壳）下，该按钮打开颜色选择框，确认后由 Minicon 绘制纯色桌面，并保存为 `winmgr.cnf` 中的 `desktop.color`（`#RRGGBB`）。桌面只使用一个不激活的窗口和一把画刷，不加载图片、不常驻位图，也不新增线程。
- 桌面窗口不会被任务栏全屏让位逻辑误判为全屏应用，任务栏不会因它铺满屏幕而退到底层。
- 清除纯色桌面目前需要把 `winmgr.cnf` 中的 `desktop.color` 改为空值后重启；界面入口与图片壁纸、桌面图标、右键菜单不在本版范围。

继续提供独立 Winmgr、Tskmgr、SHA256SUMS.txt 和 BUILDINFO.toml，官方产物按工具摘要绑定。本版验证的是纯色桌面的隔离桌面表现与候选的全屏让位、设置回归；通知面板按钮在真实替换外壳下的完整点击路径，以及物理多屏、混合 DPI 的实机表现仍未验证。

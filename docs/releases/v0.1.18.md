# v0.1.18

- Tskmgr 默认使用进程树。搜索保留祖先上下文，定位自动展开目标路径；仍可切换平面排序。
- 增加“笔记 / 标识…”：人工与 agent 可持续追加用途、观察、推测、依据和处理结果，保留作者、时间和历史。
- 支持正常、关注中、异常 / 待核实、已处理等状态，在主视图显示并可筛选；本次运行与跨重启的应用分析分别保存，避免 PID 复用串用记录。
- 新增普通权限本地 JSON 接口 `--notes-json`，与原生界面共享存储及版本冲突校验；冲突保留人工草稿，不覆盖他人的追加记录。
- 修复同目录工具已手动下载却仍请求下载的问题：官方 Winmgr 内置同版 Tskmgr 的 SHA-256，两份 exe 即可离线校验打开，无需另备校验表。
- 工具获取失败时区分本地校验、获取校验表、传输和保存阶段，提供可操作的提示；保留有效缓存回退。

使用方式和 agent 协议见[任务分析说明](https://github.com/partnernetsoftware/minicon-winmgr/blob/v0.1.18/docs/task_analysis.md)。笔记保存在本地执行账户下；不同账户不会自动同步。异常标识由人或 agent 主动设置，不等于恶意判定，不自动结束任务、提权或阻断网络。完整进程网络速率、自动异常判定和跨平台版本尚未交付。

继续提供独立 Winmgr、Tskmgr、SHA256SUMS.txt 和 BUILDINFO.toml。官方产物按工具摘要绑定；无内置摘要的开发构建仍使用原有校验表契约。不修改用户代理；另一台 Windows 的网络下载故障尚缺具体错误，不能认定代理问题已解决。

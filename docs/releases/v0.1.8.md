稳定优先，简约常驻。本版聚焦按需启动与日常交互。

### 默认开销更克制

- 默认关闭的旧菜单不再创建隐藏 UI。
- Run 启动时只注册快捷键；首次召唤才创建窗口、工作线程和轮询计时器。关闭后复用，以保留草稿和历史。
- 缩略预览仍默认关闭；未启用时不创建预览窗口。

### 操作反馈更明确

- Run 在输入时更新最近命令、本地路径和应用建议；两行列表沿用主题，支持环境变量路径，应用列表首次按需扫描。
- 修复任务管理器最小化后无法恢复及任务按钮使用旧悬停位置的问题，普通权限运行规则保持不变。
- 日常设置隐藏环境变量名称等实现细节，配置来源保留在“配置与关于”。
- 设置窗口标题尾部自动显示版本号；修复窗口类注册时临时字符串指针失效导致的初始化错误。

- 任务栏支持 Home/End 首尾导航、Enter/Space 激活，Esc 返回召唤前窗口。键盘浏览时保留原活动窗口标记，悬停文字更清晰。
- Run 选中候选时显示 Use / 采用及键盘提示；采用后仍可编辑，再次确认才执行。空白状态区隐藏，进度/错误出现时展开。
- 修复任务栏显示偏好需要重启时，保存页脚未正确提示的问题。
- 保留默认 English、中文切换、明暗/自动主题、四边停靠及紧凑原生设置；不增加任务栏常驻入口。

### 下载

Windows x64：`minicon-winmgr-v0.1.8-x86_64-windows.exe`，校验文件：`SHA256SUMS.txt`。升级前正常退出旧实例并保留配置。普通启动不请求 UAC；已提升时仍按既有规则降权。二进制尚未代码签名。

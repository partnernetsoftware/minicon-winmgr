# v0.1.17

- Winmgr 和 Tskmgr 增加“所有用户与系统任务（管理员）”入口，由用户主动授权后打开独立窗口；Winmgr 保持普通权限。
- 普通与管理员视图按角色、原用户、执行账户和会话隔离。管理员使用另一账户凭据时，原用户身份单独保留。
- 进程及网络端点增加所属用户、会话展示；筛选和已核实的进程定位可交接到管理员窗口。
- 无法核实身份的受限任务只展示元数据，不启用管理动作；系统关键进程拒绝关闭和结束。

管理员权限仍受 Windows 的访问控制与受保护进程限制。网络视图展示 TCP/UDP 端点和 TCP 状态，支持按账户、协议、状态及地址筛选；完整进程网络速率与历史趋势尚未交付。

继续提供独立的 Winmgr 与 Tskmgr 附件，以及对应校验表和构建来源。工具默认普通权限启动，不安装常驻特权服务。

# v0.1.19

- 设置窗口改为宽窗双列：左列外观与窗口行为，右列任务工具、更新、配置与关于及折叠的桌面管理；日常设置在默认窗口内不再需要纵向滚动。
- 默认窗口约 1000 × 680 DIP，并限制在当前工作区内；较窄的工作区或窗口自动回退单列，说明换行，全部设置入口仍可达。
- 保存状态与关闭按钮固定在底部；键盘顺序按左列再右列。修复缩小窗口后焦点项留在视口外的问题，窗口尺寸与 DPI 变化后焦点项保持可见。
- 设置项、保存反馈、更新与授权动作的语义不变；本版不改动任务管理、工具获取与外壳替换逻辑。

继续提供独立 Winmgr、Tskmgr、SHA256SUMS.txt 和 BUILDINFO.toml，官方产物按工具摘要绑定。本版仅验证设置布局相关路径；物理混合 DPI 仍未覆盖，既有权限、更新与进程管理行为沿用 0.1.18 的已验证范围。

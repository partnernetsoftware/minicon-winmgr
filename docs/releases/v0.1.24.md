# v0.1.24

- 发布包新增 `minicon-winmgr-v0.1.24-x86_64-windows.zip`，内含同版本 exe。裸 exe 附件保留，旧版本仍用它更新。
- 手动更新优先使用 zip：下载到程序旁的暂存文件，按 `SHA256SUMS.txt` 校验后，由 Rust 解压库只解出唯一的 exe 条目，再沿用原有的校验、替换和重启流程。解包拒绝路径穿越、符号链接、多余条目，并限制大小；失败或取消时删除暂存文件，保留旧版。
- 本版没有改变下载来源。GitHub 国内下载速度的问题仍然存在，镜像来源需要签名信任锚，留待后续版本。

升级到 0.1.24 的客户端仍走 exe 资产；zip 路径在 0.1.24 更新到之后的版本时才会被真实使用。继续提供独立 Winmgr、Tskmgr、SHA256SUMS.txt 和 BUILDINFO.toml。

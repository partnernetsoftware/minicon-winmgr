# v0.1.14

## 中文

- 时钟旁新增“显示桌面”图标，单击最小化当前虚拟桌面的应用窗口，重复点击继续最小化。支持明暗主题与四边任务栏，竖向时钟分行保留日期和时间。
- Run 新增“使用管理员权限运行”复选框，默认未选，每次重新打开复位；勾选后明确提交的目标经 Windows UAC 授权，Winmgr 自身保持普通权限。
- 授权取消或启动失败保留命令与选区，不写成功历史；等待授权时防止重复提交，旧结果不覆盖新草稿。现有候选预览、采纳与 Enter/Esc 规则保持。
- 修正设置重新显示时恢复到未选中单选项造成偏好回退的问题；补齐复用 Run 窗口的语言刷新和管理员复选框的主题绘制。

更新继续保留原安装路径和文件名；请在配置详情查看实际版本。显示桌面操作不会为了最小化被拒绝的窗口而提权。

验收限制：一次交互测试退出超时，原因尚未定位；后续取消授权检查正常退出并恢复原实例。分段结果与失败历史见[验收记录](../validation_0_1_14.md)。

## English

- Added a Show desktop icon next to the clock. It minimizes application windows on the current virtual desktop; repeated clicks continue to minimize. Supports both themes and all four docking edges, with a two-line clock on side bars.
- Added a Run as administrator checkbox to Run. It starts unchecked and resets when reopened. Explicitly submitted targets use Windows UAC; Winmgr itself remains a standard-user process.
- Cancelling authorization or failing to launch preserves the command and selection without recording success. Pending launches reject duplicate submissions, and stale results preserve newer drafts. Existing candidate and Enter/Escape behavior remains unchanged.
- Fixed settings focus restoration that could revert a radio preference, refreshed translated labels in the reusable Run window, and made the new checkbox readable in both themes.

Updates preserve the installation path and filename. Check configuration details for the running version. Show desktop does not elevate to minimize windows that refuse the request.

Validation limitation: one interactive test timed out during shutdown; the cause remains undetermined. Subsequent cancellation checks exited and restored the original instance normally. See the [validation record](../validation_0_1_14.md) for segmented results and failure history.

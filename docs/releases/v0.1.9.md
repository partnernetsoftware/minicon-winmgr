### Check / Update / Restart

- 设置新增紧凑版本区，中英文、明暗主题和键盘操作沿用原有风格。
- 用户点击才检查或下载；启动、打开设置不联网，不增加常驻网络线程。
- 只选择本仓库正式 Windows x64 版本；下载有大小、重定向与超时限制，经系统 TLS、SHA-256 及 PE 架构检查后暂存。
- 重启单独点击，设置未保存时暂不可用。普通权限临时助手等旧实例退出后备份替换，并等待新版确认启动；文件占用或启动失败时尝试回滚。其他应用保持运行，不请求 UAC。

### 下载和使用

Windows x64：`minicon-winmgr-v0.1.9-x86_64-windows.exe`，校验文件：`SHA256SUMS.txt`。首次从 0.1.8 升级请正常退出旧实例并手动替换，0.1.8 尚无本版的更新入口。保留配置，程序目录需允许当前普通用户写入。旧暂存/备份目录可在确认新版正常后手动清理。二进制尚未代码签名。

### 验收

发布前执行完整 release 层，覆盖 Rust 单元测试、设置/Run/主题与停靠，以及隔离的两版本真实更新、校验失败、文件占用和启动回滚；记录见 [验收摘要](https://github.com/partnernetsoftware/minicon-winmgr/blob/main/docs/validation.md)。测试中的 0.1.8 是当前更新器的隔离回移构建，明确区别于历史公开版。

物理混合 DPI、多屏热插拔、高对比度实屏、屏幕阅读器语音、特殊管理员令牌和小时级常驻仍需专门环境；内存长期归因暂列 0.1.10。文件系统本身损坏或持续拒绝访问时，自动回滚也可能被阻止，备份和错误记录会保留。

# v0.1.25

- 替换模式下，时钟通知面板的“桌面设置”改为一个对话框，颜色和背景图片在同一处设置：
  - 颜色：“选择颜色…”按钮，显示当前颜色值；可以设为未设置。
  - 背景图片：下拉列表，首项“无图片”，其后是系统自带的 Windows 壁纸（`%SystemRoot%\Web\Wallpaper`，最多列 300 项），以及你用“浏览…”选过的图片。
  - “确定”保存并应用，“取消”不改变设置；颜色和图片都未设置时，桌面窗口隐藏。
- 替换 0.1.23–0.1.24 中的“是 / 否 / 取消”提示框与两个单独的选择框。
- 伴随模式（Explorer 仍是外壳）下，“桌面设置”仍打开系统个性化页面。

继续提供独立 Winmgr、Tskmgr、SHA256SUMS.txt、zip 与 BUILDINFO.toml。

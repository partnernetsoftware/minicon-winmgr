# v0.1.15

## 中文

- 更新官方版本化 exe 后，程序采用新版本文件名，保持安装目录；实际进程路径不再沿用旧版本号。固定名和自定义名保持原命名。
- 兼容已发布旧更新器的首次交接：新路径实例实际就绪后才确认成功。目标名冲突拒绝覆盖，启动失败恢复原文件名与旧版本。
- 自动迁移精确指向旧程序的本产品当前用户登录 Shell，保留原始外壳恢复记录；Winmgr 保持普通权限运行。

自建快捷方式、计划任务及第三方启动器不会被扫描、检测或自动迁移。官方版本化文件更名后，请手动更新这些入口；需要稳定路径时可使用固定名/自定义名。设置详情亦提供说明。本版不包含 Tskmgr/Sysmgr 或插件系统。

## English

- Updates to officially versioned executables now use the new version's filename in the same installation directory. Stable and custom filenames retain their names.
- Supports the first handoff from previously published updaters. Success requires the actual new-path instance to become ready. Existing destination files are never overwritten; startup failure restores the old filename and version.
- Migrates only this product's exactly matching current-user login Shell reference, retaining the original shell recovery record. Winmgr remains a standard-user process.

Custom shortcuts, scheduled tasks and third-party launchers are not scanned, detected or automatically migrated. Update those entries manually after a versioned filename changes; use a stable/custom filename when a stable path is needed. Configuration details also explain this boundary. Tskmgr/Sysmgr and a plugin system are not included.

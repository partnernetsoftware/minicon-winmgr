# v0.1.23

- 替换模式下，桌面可以使用一张照片作为背景。在时钟通知面板的“桌面设置”中选择“是”即可选择图片（jpg、jpeg、png、bmp），选择“否”仍然是纯色，“取消”不改变设置。
- 照片按屏幕铺满并居中裁剪，逐段解码绘制：每次只保留 32 行像素，不常驻整屏位图。照片读取失败时保留纯色背景并记录日志。
- 配置项 `desktop.wallpaper` 保存照片路径；清除照片需要把它改为空值后重启，界面入口留待后续版本。
- 伴随模式（Explorer 仍是外壳）下，“桌面设置”仍打开系统个性化页面，本版不改变。

继续提供独立 Winmgr、Tskmgr、SHA256SUMS.txt 和 BUILDINFO.toml，官方产物按工具摘要绑定。

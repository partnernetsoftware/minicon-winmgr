# v0.1.16 — 我的任务

新增独立的 Minicon Tskmgr，管理当前用户的应用、进程和基础网络端点。Winmgr 保持普通权限，工具独立运行和退出。

- 查看 CPU、工作集/专用内存、PID、会话、路径和按需读取的命令行，支持搜索、排序及进程树。
- 切换窗口、正常关闭、打开文件位置、复制信息；结束进程需要明确确认，默认取消，执行前复核进程身份。
- 查看 IPv4/IPv6 TCP/UDP 端点及进程归属。本版不提供实时网络速率，不可读取的数据明确保留为不可用。
- Winmgr 设置增加“我的任务”；窗口右键菜单可定位对应进程，并保留 Windows 任务管理器入口。

下载 `minicon-winmgr-v0.1.16-x86_64-windows.exe` 可继续使用原有单程序更新方式。首次打开“我的任务”时，如果没有匹配且校验通过的工具，会询问是否从本版本公开发布下载；下载和校验在后台执行，失败可重试。

离线部署可把两份 exe 和 `SHA256SUMS.txt` 放在同一目录。`minicon-tskmgr-v0.1.16-x86_64-windows.exe` 也能独立运行。工具按版本缓存，Winmgr 更新不会覆盖正在运行的旧工具。

管理员“所有用户与系统任务”入口属于后续版本。本版不安装服务或驱动。

# v0.1.26

- 设置面板新增“强调色”：可选择界面强调色，并可恢复默认。强调色与桌面设置共用同一个拾色对话框。
- 对比度保护：强调色在某个明暗模式下与背景或面板色的对比度不足 3:1 时，该模式自动使用默认强调色，设置值保留，换到能读清的模式时重新生效。
- 设置面板更紧凑：强调色的标题直接显示当前值（如“强调色 · 默认”），两个按钮并排，只有对比度不足时才显示说明行。
- 桌面设置对话框增加“清除”按钮，可把颜色设为未设置。0.1.25 缺少此按钮，已修正。
- 对话框沿用应用的外观设置（暗色标题栏、按钮风格）。

继续提供独立 Winmgr、Tskmgr、SHA256SUMS.txt、zip 与 BUILDINFO.toml。背景与表面色仍不开放界面；图片缩略图预览顺延。

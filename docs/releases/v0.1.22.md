# v0.1.22

- 修复 0.1.21 的替换模式纯色桌面：在通知面板“桌面设置”中选择颜色并确认后，颜色现在会保存为 `winmgr.cnf` 的 `desktop.color`，并由 Minicon 绘制到桌面上。0.1.21 中该保存路径被设置白名单遗漏而失败，外壳仍能正常运行，但颜色不生效。
- 其余行为与 0.1.21 相同：伴随模式下“桌面设置”仍打开系统背景页；纯色桌面只使用一个不激活的窗口和一把画刷。

请更新到 0.1.22 后重新选择颜色。清除纯色桌面仍需把 `winmgr.cnf` 中的 `desktop.color` 改为空值后重启；图片壁纸、桌面图标与右键菜单不在本版范围。

继续提供独立 Winmgr、Tskmgr、SHA256SUMS.txt 和 BUILDINFO.toml，官方产物按工具摘要绑定。

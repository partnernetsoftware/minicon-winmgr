# v0.1.29

- 程序带图标与版本信息：`minicon-winmgr.exe` 与 `minicon-tskmgr.exe` 的文件属性显示产品名 Minicon Winmgr、发行者 PARTNERNET SOFTWARE PTY LTD 与文件说明。
- 外壳与任务管理器由公司 Azure Artifact Signing 签名（Authenticode，带 RFC 3161 时间戳）。发布清单 `docs/releases/v0.1.29.artifact.toml` 记录签名运行，并绑定签名后的摘要。
- 发布路径改为接受签名工作流的产物；`release-policy.json` 设为 `required`，签名缺失或发行者不符时拒绝发布。

# 0.1.11 — Safer startup and clearer command selection

Windows x64.

- Elevated startup must relaunch the same user in the same session with standard privileges before initializing the desktop. If relaunch fails, the elevated process reports the error and exits.
- Notification hosting recognizes another installed build of minicon-winmgr as this product, restoring notification icons in that shell configuration.
- The taskbar clock shows `Www yyyy-mm-dd HH:MM`, for example `Sat 2026-10-17 18:30`.
- Run previews the selected command in the input when you move with Up/Down. Escape restores the draft; Enter adopts the selection, and another Enter runs it. Editing continues from the previewed command.
- Default logs are separated by Windows account. Localized error-message tests now run in isolated child processes.

The release promotes the exact CI candidate used for acceptance. `SHA256SUMS.txt` and `BUILDINFO.toml` accompany the executable. Binaries are not code signed.

From 0.1.10, use **Check → Update → Restart**. Older versions can download and launch the new file, then confirm the running-instance switch. Ordinary startup does not change the sign-in shell registration.

Extended 2h/8h resource observations and physical display/accessibility, special-token, real IME and public-network fault matrices remain separate work. See the [acceptance record](https://github.com/partnernetsoftware/minicon-winmgr/blob/main/docs/validation_0_1_11.md) for the actual scope.

# 0.1.11 — 启动权限、时钟与 Run 候选预览

Windows x64。

- 管理员入口必须以同用户、同会话普通权限重启自身后初始化桌面；降权失败时提示并退出。
- 登录外壳指向本产品另一份构建时仍正确识别，恢复该场景的通知图标宿主。
- 日期改为 `Www yyyy-mm-dd HH:MM`，例如 `Sat 2026-10-17 18:30`。
- Run 上下切换候选时同步预览到输入框；Esc 恢复草稿，Enter 采纳、再次 Enter 执行，继续输入可修改预览命令。
- 默认日志按 Windows 账户隔离；本地化错误文案测试使用独立子进程。

正式附件原样晋升已验收的 CI 候选，附带 SHA-256 和公开构建身份，二进制尚未签名。0.1.10 可通过“检查更新 → 更新 → 重启”升级；更旧版可下载启动后确认切换。普通启动不会改写登录外壳。

2h/8h、物理显示与无障碍、特殊令牌、真实 IME 和公网故障矩阵仍独立跟踪，实际完成范围见验收记录。

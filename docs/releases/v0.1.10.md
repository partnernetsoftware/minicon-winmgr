# 0.1.10 — A steadier desktop, your way

Windows x64. Extended two/eight-hour resource observations are tracked separately and have not completed.

## Everyday improvements

- **Make room for your work.** Drag the inner edge of a left or right taskbar to adjust its width. Maximized windows now reach the bottom correctly after moving the taskbar to either side.
- **Keep your preferences.** Settings are saved in `~/winmgr.cnf` and restored when you launch without arguments. Existing executable-adjacent preferences migrate on the first successful save; the original file remains.
- **Open the Recycle Bin from the clock panel.** The shortcut supports English/Chinese, light/dark themes and keyboard navigation.
- **Switch versions explicitly.** Starting a different winmgr build asks before replacing the running instance, including 0.1.4. Cancel leaves it running; confirmation requests a normal exit. No forced termination, elevation or sign-in shell change.

## Reliability and resource work

Hover previews use one DWM composition relationship, and window icons are queried by one bounded worker. Logs, pending work and diagnostic samples have explicit limits. Update downloads and verification use streaming buffers, with cancellation and recovery paths.

Resource observation is optional under **Configuration & About → Diagnostics**. It records only after you start, stops when closed, and can export a numeric summary. Startup does not check for updates or begin diagnostic recording.

Three fresh-process window-lifecycle comparisons and the functional release regressions passed. Results describe that scenario; component experiments do not establish a whole-application improvement percentage or a zero-leak guarantee. See the [0.1.10 evidence](https://github.com/partnernetsoftware/minicon-winmgr/blob/main/docs/validation_0_1_10.md).

## Download and upgrade

The Windows x64 asset is `minicon-winmgr-v0.1.10-x86_64-windows.exe`, accompanied by `SHA256SUMS.txt` and public build provenance. The release promotes the exact CI file used in acceptance.

From 0.1.9, use **Check → Update → Restart** after publication. For older versions, download and launch the new executable; confirm the running-instance switch when offered. To keep using the new file after sign-in, choose the desktop-management action explicitly. Ordinary launches do not rewrite your sign-in shell. Binaries are not code signed.

# 0.1.10 — 桌面稳一些，工作顺一些

Windows x64；2h/8h 扩展资源观察独立跟踪，尚未完成。

- **把空间留给工作。** 左右任务条可拖动内侧边缘调整宽度；修复换到左右侧后最大化窗口底部留空。
- **设置跟着用户走。** 偏好保存到 `~/winmgr.cnf`，无参数启动即可恢复；旧设置首次成功保存时迁入，原文件保留。
- **少找一个入口。** 点击时间打开的小面板新增回收站，中英、明暗与键盘操作同步支持。
- **换版本先询问。** 兼容检测 0.1.4 等旧实例，默认取消，确认后正常交接，不强杀、不提权、不改登录外壳。

资源加固包括单个 DWM 预览、有界图标 worker、日志与队列预算、流式下载校验、网络取消及恢复。诊断放在“配置与关于 → 诊断”，明确开始后才记录，关闭即停止；启动不检查更新、不启动诊断。

三组窗口生命周期资源对照和完整功能回归通过；数据只描述所测场景，组件实验不能冒充整应用优化比例或零泄漏保证。发布文件与测量、验收使用的 CI 文件完全一致。

正式发布后，0.1.9 可按“检查更新 → 更新 → 重启”升级；更旧版本可下载并启动新版，在提示时确认切换。若要后续登录使用新文件，需显式执行桌面管理动作；普通启动不会改写登录外壳。二进制尚未代码签名。

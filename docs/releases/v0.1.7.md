更紧凑的原生设置、多语言与四边任务栏。

### 新增与改进

- English / 中文界面，默认 **English**；在设置中即时切换并保存。
- 暖白、鞍棕与深炭配色；Light / Dark / Auto 三种主题，Auto 跟随 Windows 应用主题。
- 任务栏支持上、下、左、右停靠；竖向任务列表正常显示标题，通知与时钟保留底部位置。
- 设置采用紧凑分组与折叠桌面管理，配置详情可选择复制；README 包含中英文、明暗主题四张真实截图。
- 检测到自身已提升权限时，以同用户、同会话的普通权限重新启动；普通启动直接运行，**不会主动请求 UAC**。
- 修复连续换边时工作区基线偏移；切换基于原始快照计算，退出恢复原始工作区。
- 开发测试支持按层与模块选择；发布前执行完整 release 验收。

### 下载与校验

下载 `minicon-winmgr-v0.1.7-x86_64-windows.exe`，适用于 Windows x64。已有实例时先正常退出旧版本，再运行新版本；个人配置请保留。附件 `SHA256SUMS.txt` 用于校验下载文件。

普通使用无需管理员权限。外壳接管是单独的显式操作，请先阅读仓库中的接管与回滚说明。

### 验证与限制

格式、严格 Clippy、261 项 release 单测，以及设置、Run、语言/布局、主题/四边完整桌面自动化均通过。发布验证记录见仓库 [验收摘要](https://github.com/partnernetsoftware/minicon-winmgr/blob/main/docs/validation.md)。物理多屏/混合 DPI、高对比度实屏、屏幕阅读器语音、特殊管理员令牌与小时级常驻仍需专门环境；本版没有完成内存长期归因研究。二进制尚未代码签名。

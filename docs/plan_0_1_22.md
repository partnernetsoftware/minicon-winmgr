# 0.1.22 计划：修复替换模式纯色桌面的保存失败

状态：开发中（main，未打 tag、未公开）。

## 1. 问题

0.1.21 公开后，替换模式下用户在“桌面设置”选择颜色并确认，颜色没有生效，配置也未保存。

根因：`settings_store::enqueue` 只接受白名单内的设置键，`desktop.color` 没有加入白名单。颜色选择框确认后，`set_desktop_color` 触发断言 panic；panic 在 FFI 回调中被 `guard_abi` 捕获，外壳保持运行，但颜色既没保存，也没有应用，桌面窗口因此从未创建。

证据：运行中的 0.1.21 日志有两次 “panic crossed an FFI callback”，位置为 `settings_store.rs` 的断言；`winmgr.cnf` 中没有 `desktop.color`；桌面窗口类 `minicon_winmgr_desktop` 不存在。Explorer 未运行，Minicon 确为外壳，因此不是外壳判定的问题。

0.1.21 的发布附件已经公开，按发布规则不覆盖，修复以新版本发布。

# minicon-winmgr — UI/UX 设计语言

> 定位：Cairo 级外壳里的**效率条**。不是壁纸/装饰系统，而是一条"看一眼就知道系统在干什么、点一下就能切过去"的极简任务栏。
> 关联：`docs/prd.md`（需求树）、`src/taskbar.rs`（实现）。

---

## 1. 设计原则

1. **内容优先，chrome 最小** — 没有大图标、没有开始按钮装饰、没有渐变阴影。任务栏只承载信息本身。
2. **一屏一焦点** — 同一时刻只有一个"当前窗口"高亮；hover 只给一个中性反馈，不喧宾夺主。
3. **静默美学** — 深色、低对比背景；颜色只在 hover / active 两处作为信号出现。
4. **效率第一** — 36px 单行、文本优先、点击即切换；窗口标题可读优先于图标识别。
5. **可观测内建** — 任务数与时间是常驻信息，不需要另开面板。

## 2. 视觉规范（design tokens）

| Token | 值 | 用途 |
|-------|----|------|
| `bar.height` | 36 px | 任务栏高度 |
| `bar.padding` | 10 px | 左右内边距 |
| `bar.gap` | 4 px | 按钮间距 |
| `bar.rightZone` | 92 px | 右侧时钟/计数区 |
| `button.min` / `max` | 120 / 200 px | 按钮宽度夹取 |
| `radius` | 4 px | 按钮圆角（GDI 近似为平角，后续可上 DWM/圆角） |
| `font` | Segoe UI 12px | 常规；激活态加粗 |

**色板（深色 / `COLORREF 0x00BBGGRR`）**

| 名称 | RGB | COLORREF | 用途 |
|------|-----|----------|------|
| `bg` | 27,27,31 | `0x001F1B1B` | 栏背景 |
| `surface` | 38,38,44 | `0x002C2626` | 按钮静止态 |
| `surfaceHover` | 51,51,59 | `0x003B3333` | 按钮 hover |
| `accent` | 76,139,245 | `0x00F58B4C` | 激活窗口 / 品牌点 |
| `text` | 230,230,230 | `0x00E6E6E6` | 主文字 |
| `textMuted` | 154,154,162 | `0x00A29A9A` | 次要文字（时钟/计数/占位） |

## 3. 布局（anatomy）

```text
┌──────────────────────────────────────────────────────────────────────┐
│ ●  [ ▍Sourcetree ] [ 终端 · myrmux ] [ Cairo ]           3 任务  14:07 │
└──────────────────────────────────────────────────────────────────────┘
  ↑                  ↑                                        ↑
  品牌点(accent)     任务按钮(文本优先, 激活态 accent 左条)      右侧只读区
```

- **品牌点**：一个 6px accent 圆点作为"握把"，不放文字，降低噪声。
- **任务按钮**：宽度自适应 `clamp(可用宽/任务数, 120, 200)`；标题 `DT_END_ELLIPSIS` 截断。
- **右侧只读区**：`N 任务` + `HH:mm`（24h，muted）。

## 4. 交互

| 事件 | 行为 |
|------|------|
| hover 按钮 | 填充 `surfaceHover` |
| 离开栏 | 清除 hover（`TrackMouseEvent` + `WM_MOUSELEAVE`） |
| 左键点击按钮 | 激活窗口；若最小化先 `SW_RESTORE` 再 `SetForegroundWindow` |
| 心跳 / 窗口变化 | 重新枚举任务并重绘（默认 30s，鼠标进入时立即刷新） |
| 鼠标进入栏 | 触发一次即时刷新，保证任务列表"新鲜" |
| `Alt+`` | 唤出任务栏并进入键盘导航（光标落到第一个任务） |
| `←` / `→` | 移动键盘光标（accent 描边），环绕 |
| `Enter` | 切换到选中任务并退出导航 |
| `Esc` / 失焦 | 取消导航 |

## 5. 与 Cairo Desktop 的差异

| 维度 | Cairo | minicon-winmgr |
|------|-------|----------------|
| 取向 | 桌面环境（壁纸、图标、动态桌面） | **效率条**：只做窗口切换 + 状态 |
| 视觉 | 图标 + 分类堆叠 | **文本优先**、无图标、更低矮 |
| 差异化 | — | 会话可观测（WTS）+ 受控外壳切换内建 |

## 6. 落地状态与后续

- ✅ 自绘任务栏首版（M3+）：深色、文本优先、hover/active、点击切窗、时钟+计数。
- ✅ 圆角 / 亚克力（DWM，`src/dwm.rs`）：圆角用 `DWMWA_WINDOW_CORNER_PREFERENCE`（Win11，默认开启）；亚克力用 `DWMWA_SYSTEMBACKDROP_TYPE`+扩展边框（**opt-in `MINICON_ACRYLIC=1`**）。两者均优雅降级——不支持的 OS 回退为方角 / 不透明栏（Windows Server 2022 实测均不支持，已记日志）。
- ✅ 键盘导航：全局热键 **Alt+`** 唤出并聚焦任务栏，**←/→** 移动选择（accent 描边），**Enter** 切换到选中任务，**Esc** 取消；失焦自动清除光标。环绕逻辑有单元测试。
- ✅ 任务分组 / 同应用多窗口折叠：按 pid 归组，多窗口显示 `标题 (+N)`（`src/grouping.rs`）。实测 11 窗口 → 8 组。
- ✅ 多显示器每屏一栏：每个显示器工作区各一条栏，任务列表共享、布局/hover/键盘光标按窗口独立（`src/taskbar.rs`）。
- ✅ 主题可配置：颜色来自 `config`（`minicon.conf` 或 `MINICON_CONFIG`），默认值与本文档色板一致。
- ⬜ 系统托盘镜像。
- ⬜ 应用启动器 UI（检索逻辑已在 `src/launcher.rs`，暂以 `--launch` CLI 暴露）。

## 当前阻塞与剩余验收

最终候选的发布层已通过质量、普通优化单元及资源组件，准备进入真实桌面时 OpenInputDesktop 因会话断开失败，在关闭原实例之前停止。原程序仍运行，二进制摘要保持不变；没有操作其他账户的桌面。

解锁后继续同一候选的原生诊断、侧栏、当前回移/真正公开 .11 更新、任务管理器、日常交互、设置/Run、布局/主题、实际诊断与 DWM hover、换边/回收站，以及官方 .4 的双语切换。所有恢复结果与准确摘要分别记录，不能以旧候选或单个 HWND 冒充通过。

完成后才合 main/tag，晋升同一 CI 文件为草稿、核验附件并公开；公开后验证真实 .11 → .12 更新。原始报告和未公开截图只留在忽略的 target 目录。

## 开发期修正与旧候选

首份候选 39093762400、第二份候选 39094499979 的完整功能层均已通过，设置三行状态的中英/明暗四张自有窗口图片也已审阅。它们随后被当前候选替代，不能直接算作最终摘要的桌面验收。

额外本地优化复核发现旧 HTTP fixture 在 20ms 客户端预算先耗尽时无限 accept，已给测试夹具增加完成信号及有界 accept/read/write；产品 HTTP 实现和原结果断言不变。后续就绪复核发现启动器创建成功不等于热键可达，补实际注册状态、独立/共同运行策略及接管前 Ready 探测，并用故障 fixture 验证。因此两次重新构建候选，保留失败原始输出，不将重试前的等待或未完成项记为通过。

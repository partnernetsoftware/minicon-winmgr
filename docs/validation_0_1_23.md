| 目标 | 单次绘制 | 工作集变化 | 私有内存变化 |
|---|---|---|---|
| 1920×1080 | 约 100 ms | 约 8.3 → 10.1 MB（含首次加载 WIC 组件） | 约 1.68 → 1.92 MB |
| 3840×2160 | 约 129 ms | 约 10.2 → 10.2 MB | 约 1.92 → 2.11 MB |

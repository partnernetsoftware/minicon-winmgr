## 风险、证据与结论

| 风险 | 直接证据 | 结论 |
|---|---|---|
| 陈旧 PID 或不同账户被操作 | 原生动作按 SID 与 PID/创建时间复核；错误创建时间结束自有子进程被拒绝且子进程仍存活；进程树与 CPU 身份规则定向单元 | 身份保护通过；不声称能操作受保护或其他用户目标 |
| 列表与命令行伪造/错配 | 真实自有进程、Unicode 命令行、窗口标题搜索；IPv4/IPv6 TCP/UDP 自有端点采样；原生网络视图 | 查询、搜索和端点归属通过；缺失字段不伪造零或速率 |
| 挂起目标阻塞界面 | 自有窗口停滞期间激活有失败反馈，工具消息响应正常；恢复后的窗口可还原并激活 | 窗口动作不阻塞界面 |
| 关闭/结束语义错误 | 自有窗口正常关闭后实际进程句柄结束，启动器正常退出；结束默认取消、取消保留目标，明确确认后实际目标退出 | 正常关闭与结束分别验证，不以请求成功冒充退出 |
| 路径操作不正确 | 打开位置后通过 Shell COM 核对实际 exe 所在目录及选中文件，关闭仅本次新开的文件夹窗口 | 打开位置通过 |
| 外壳与工具生命周期耦合 | 准确主程序实际设置页键盘入口；缺失时默认取消、外壳响应；同目录校验和版本缓存均能打开工具；关闭工具后外壳继续运行；最终恢复正式外壳、工作区和 Shell | 新入口与独立退出通过 |
| 缓存或交付污染 | 下载中断、错误内容、重试、已装缓存再校验、错误版本、目标冲突保留定向验证；双程序晋升原样复制，工具篡改拒绝，旧版五字段仍支持 | 组件与晋升约束通过，真实公开下载待发布后核实 |
| 刷新带来持续开销 | 准确工具短时空闲、增加 32 个自有启动目标、退出负载及最小化；全部消息探测响应，正常退出 | 本机约半分钟观察通过；不作为小时级泄漏或极限规模认证 |

短时观察中，工具线程数维持 25，句柄约 362–363，私有提交约 9.5–10.1 MiB；负载时可见进程从约 138 增至 234，负载退出后回落；最小化阶段工具 CPU 时间未增长。启动器会派生额外解释器进程，观察中的进程增长不误称为只有 32 个 OS 进程。负载受自有 Job 限制并完整清理。

## 失败与限制

首次原生探针在正常关闭处失败：完成前一个异步激活动作后按钮仍被禁用，探针提前点击。定向诊断直接记录 `before_close_enabled=false`、`Working…`；等待按钮可用后，实际目标句柄结束、启动器退出 0。后续仅补测关闭及尚未执行的结束/取消与翻译路径，保留失败报告，没有修改产品关闭语义或放宽退出断言。诊断脚本曾等待错误提示词，修正为直接核对进程退出，未作为产品失败或通过计数。

中英和明暗代表截图已目视核对，当前桌面 DPI 下布局可用；物理混合 DPI/多屏和屏幕阅读器未覆盖。复制信息控件可用性及 Unicode 剪贴板实现经核对，尚未实际写入用户现有图像剪贴板；尝试建立独立窗口站的探针在环境准备阶段收到拒绝访问，没有改权限或修改用户剪贴板。源码/组件检查与实际复制不是同一种证据。

当前验证均未触发 UAC、修改登录注册表或用户安装文件。正常外壳仍为用户原先运行的版本，不把候选测试冒充用户已安装升级。

# 0.1.15 计划：更新路径正确与结果可确认

状态：更新文件名修复已合 main，开发验证与 CI 通过；尚未生成或发布 0.1.15 正式候选。新增功能仅作待讨论建议，未实施、未计入必交付范围。更新：2026-10-19。

当前公开版仍为 [v0.1.14](https://github.com/partnernetsoftware/minicon-winmgr/releases/tag/v0.1.14)。用户已明确将更新文件名修复纳入 0.1.15；具体行为和开发证据以[修复规格](update_filename_fix.md)为准。本计划不替换或重发 0.1.14 附件。

## 1. 本版目标与范围

解决“界面已经是新版，实际进程路径却仍带旧版本号”的问题，让更新后的文件名、实际运行路径和程序版本相符，并保留旧版首次交接与失败回滚能力。

已确定范围：官方版本化文件名随更新变更；兼容已发布旧 helper；冲突保护、回滚和精确匹配的登录 Shell 引用迁移。无版本固定名和用户自定义名按现有明确命名处理。发布前需明确用户自建快捷方式、计划任务等外部入口的支持与反馈边界，不能把当前仅迁移登录 Shell 写成所有启动引用均已处理。

新确认的 Tskmgr/Sysmgr 产品方向不进入本版：先公开交付更新修复；后续普通任务入口、按需管理员管理与整机监控见[路线](roadmap_0_1.md)及[工具 PRD](prd_7_1.md)。不为新工具提前重构更新器、建立插件平台或增加常驻特权服务。

原旧启动器后台化、pin/recents 存储迁移和容量研究完整保留于[维护备选草案](archive/plan_0_1_15_maintenance_draft.md)，继续待讨论，不默认安排到本版或下一版本。

外部入口边界已收口：本版不扫描、不检测也不自动改写用户自建快捷方式、计划任务或第三方启动器。设置详情与发布说明告知用户在版本化文件更名后手动更新这些入口；固定名/自定义名可保留稳定路径。仅本产品精确匹配的 HKCU 登录 Shell 引用自动迁移，不声称提供了外部入口检测。

## 4. 适合加入的功能建议（待讨论）

本次梳理建议 .15 以修复交付为主，默认不捆绑这三个可选项。若选择加项仍优先 F1；F2 需额外结果状态设计，F3 次选。它们尚未批准实施，不因写入本计划就成为发布门槛，也不自动顺延至 .16。

| ID / 建议优先级 | 功能与用户价值 | 最小范围与验收边界 |
|---|---|---|
| F1 · 优先推荐 | **打开程序所在文件夹**：在设置中直接定位当前实际运行的 exe，便于核对版本文件、备份或处理便携安装。 | 一个清楚的设置入口，打开文件夹并选中当前进程的 exe；依据实际路径，不猜下载目录或旧文件名。普通权限执行，失败反馈可见，中英及键盘可用。现有配置详情已有路径文字，该功能补上直接操作。 |
| F2 · 推荐讨论 | **更新结果摘要**：重启后明确显示更新完成，或失败后已恢复旧版，减少“到底换成功没有”的猜测。 | 设置中显示最近一次已确认结果及当前版本，可与 F1 联动。必须依据真实就绪与回滚结果；旧 helper 没有可靠来源版本时只展示已确认的新版本，不从旧文件名猜版本。不自动弹窗、不联网报送，只保存有界的最近一条记录。 |
| F3 · 次选 | **删除单条 Run 历史**：移除误输或含私人参数的一条命令，不必清空整个历史。 | 仅删除明确标为历史的条目，菜单与键盘可到达；不删除路径建议或目标文件。保留当前 Enter/Esc 和预览规则。写盘失败需如实反馈，不能声称下次启动也已删除。 |

如果只加一个功能，建议 F1；如果再加一个，选择 F2。新功能的交互细节和验收用例在确认选择后补充，不在本轮直接改代码。

## 5. 新增维护跟踪（不自动排期）

0.1.14 的真实 UAC 测试中，一轮正常 WM_CLOSE/WM_DESTROY 后进程未在 8 秒内退出，原因尚未定位；当时已核实身份后仅清理自有测试实例并恢复原运行环境。后续取消授权轮次退出与恢复正常，尚不能据此宣称该问题已修复。详见[验收记录](validation_0_1_14.md)。

本版退出回归注意保留分阶段证据；若复现影响使用的退出缺陷，先作必要修复再发布。不以强制结束进程代替正常退出验收，也不因此启动存储迁移或后台化草案。更新修复不改变权限路径，不额外安排交替 UAC 弹窗。

## 6. 发布完成条件

准确 .15 文件通过选定范围的回归；发布和 main CI 成功；三个附件与已验收候选一致；真实公开 .14 更新器下载到 .15、校验及显式重启成功，实际进程使用 .15 文件名且原环境可恢复。未支持的外部入口及物理多屏、SMB、无障碍、长期观察按实际覆盖记录。

公开交付后再将被替代的 .14 计划归档，更新 README、PRD、索引及验收摘要；当前仍保留 .14 为公开版本事实。

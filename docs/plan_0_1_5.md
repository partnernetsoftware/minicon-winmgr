# plan_0_1_5 — 0.1.5 版本计划

> 起草：2026-10-14 · 上一版：v0.1.4（已公开发布）· 状态：✅ 0.1.5 交付验收完成（2026-10-15）；发布状态以 GitHub Release 为准。
> 主题：**通知区域图标达到日常可用**。需求唯一来源：[`prd_1_1_2.md`](prd_1_1_2.md)。

## 1. 交付目标

补齐任务栏时钟旁的通知图标：真实应用图标能出现、能操作，溢出后可从向上箭头面板找到；外壳重启和应用退出不留下不可用残影。音量/网络系统入口与应用托盘兼容性分开交付和说明。

0.1.4 保留已发布的运行对话框交付记录，不向其追加未实现需求。本版以0.1.3通知区基础为起点，不将已有模块或单测标记视为本轮完成。0.2.0 任务栏拆分/长跑继续保留；本版不扩大到通知中心、Toast历史或完整复刻Windows系统托盘。

## 4. 交付记录

- 2026-10-14：用户澄清tray icon bar指通知区域图标；0.1.4已发布，需求排入0.1.5。当前所有切片及验收均待执行。
- 实机基线：真实Shell_NotifyIconW注册/删除均返回FALSE。调试确认系统发送magic+操作号+32位编组结构，旧实现误按操作号+原生64位结构解析，且始终返回失败；已修首层解码、成功回执及部分字段更新，8项宿主测试通过，真实链路复验进行中。面板与完整兼容性仍未交付。
- 接入进展：原生通知面板已可通过Win+B进入，主条最多4项并按隐藏/溢出显示箭头；真实桌面已看到两个现有应用图标。带消息泵的Shell_NotifyIconW探针注册6项、NIM_SETVERSION(4)、NIS_HIDDEN更新均返回TRUE，SendInput实际点击后收到ID=41的NIN_SELECT(0x400)和WM_CONTEXTMENU(0x7b)回调。此证据尚不证明真实应用菜单、双击、全部键盘行为通过。
- 当前检查：251项测试通过；面板接入的cargo check通过。Clippy发现一处多余return，已修，待复跑。桌面截图保存在本机忽略目录`.workbuddy/captures/notification-overflow.png`，后续交付需归档可复核证据。
- 系统入口实测限制：当前Windows Server的`ms-settings:sound`返回31，已加入后台启动和`control.exe mmsys.cpl`/`ncpa.cpl`回退，待实机复验。未将入口标记为交付。
- 新增可复用实机客户端：`scripts/notification_probe.py`（标准库ctypes，支持普通ID/GUID、版本0/3/4、隐藏、部分提示更新、循环及TaskbarCreated恢复）。GUID模式8项在外壳重启后再次注册成功，探针记录重注册2次、无失败操作。
- 桌面交互补充：网易UU远程、WorkBuddy的真实右键菜单均能显示并Esc关闭；网易UU远程的旧协议Shift+F10菜单已通。版本4探针通过SendInput方向键定位、Enter/Space各收到一次NIN_KEYSELECT，Shift+F10收到WM_CONTEXTMENU，Esc关闭面板。实测修复了BS_NOTIFY焦点通知误激活和F10系统按键未处理的问题。
- 音量回退复验：原生按钮调用后实际出现“声音”控制面板；仅证明入口到系统窗口链路，不代表音量状态监控。网络仍待验。
- 资源局部证据：真实Shell_NotifyIcon客户端100轮add/部分tip/hidden/delete，共400次操作全部TRUE。另在同一进程、8探针图标加现有应用下，原生WM_HOTKEY/WM_CLOSE执行面板100轮，句柄366→364、GDI50→50、USER73→73；WS36.85→36.97MiB、private13.95→15.06MiB（首次循环有堆缓存增长，仍需最终版本同条件复验）。此资源循环不冒充100轮SendInput键盘验收；实际键盘证据单列于上。
- 异常退出复验：核对探针HWND所属PID后仅终止自建探针进程，8个探针图标在0.567秒内从已展开面板移除，两个原有应用图标仍保留。首次使用已退出探针的旧报告时PID校验正确拒绝了终止操作，随后换新探针完成验证。
- 系统入口键盘复验：SendInput执行Win+B、Tab到目标、Enter，分别出现“声音”和“网络连接”系统窗口；网络窗口2.99秒内打开，Shell_TrayWnd保持原句柄。未修改音量、网络设置或默认外壳。
- 已推送main实现提交`c62dfc7`；对应[Windows CI](https://github.com/partnernetsoftware/minicon-winmgr/actions/runs/38585684928)的fmt、严格Clippy和251项测试通过。该提交是开发检查点，尚未打0.1.5标签；最终版本仍需覆盖剩余矩阵。

## 6. 最终候选复验（2026-10-15）

- 接续未提交修复：版本0/3/4的抬起/双击序列；按住期间合并更新，松开后定时补刷新；发送前核对当前注册，删除目标时不向邻居误发。
- 分页面板按工作区缩减列数、保持目标身份、使用当前DPI系统字体；隐藏时先销毁控件再释放图标快照，避免关闭面板后仍持有已退出应用图标。无图标及系统入口仍可操作。
- 253项测试、fmt、严格Clippy、独立目录release构建通过。旧release文件被运行实例占用，先构建到独立目录，成功后才优雅热切换到live副本；未先停外壳再编译。
- live副本路径与注册表配置路径不同，因此复验显式设置 `MINICON_TRAY_HOST=1`，未修改外壳注册表。其他RDP会话实例未停止。实际Explorer伴随验证也保留其已有通知宿主。
- 最终原生输入覆盖两实际应用、0/3/4协议、主条箭头、按住删除、70图标分页；面板100轮资源循环通过WM_HOTKEY/WM_CLOSE驱动，不冒充100轮SendInput用户输入。
- 探针JSON报告原子替换增加Windows共享冲突短暂重试；桌面脚本等控件重建完成后再读状态。脚本或采样失败不计作产品验收通过，修正后复验。
- 资源数据为同进程同图标数量对照：100轮句柄357→357，GDI240→240，USER121→121，private13.95→13.86MiB；10临时项删除后GDI60→30、USER63→51，回到基线。
- 最终截图留在本机忽略目录，已目视核对真实菜单；仓内存放去除宿主路径的验收摘要，避免将用户应用内容截图公开。
- 发布流程：main精确文件提交 → 对应Windows CI成功 → v0.1.5标签 → Release构建/资产下载验证。物理混合DPI、跨屏/拔插和数小时长跑不在本版已验证范围。

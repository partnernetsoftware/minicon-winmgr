# 0.1.24 计划（设计稿）：更新分发优化

状态：设计稿，未开工，版本号仍为 0.1.23。需求与待决策项见 [prd_1_1_3.md](prd_1_1_3.md)。实施前须先确认该文件 §6 的决策 D1–D5。

## 1. 目标

- 下载可达：国内网络下更新可用，且不降低完整性保证。
- 发布包改为 `.zip`，客户端用 Rust 解压 crate 解包，不调用系统工具。
- 解压与下载保持流式、有界，峰值内存可实测。

├── [ ] 决策确认：D1 镜像主机、D2 版本发现、D3 签名与私钥、D4 过渡策略、D5 工具打包

## 3. 风险

- 签名没有落地前，任何镜像都不能作为自动更新源（见 PRD §3.4）。
- 过渡期同时发布 exe 与 zip 会增加附件数量与发布校验工作量，需在候选与草稿比对中覆盖。
- zip 解压依赖新增 crate，需确认许可、体积与安全记录。

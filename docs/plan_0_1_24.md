## 2. 风险

- zip 暂存文件与 exe 同目录，磁盘不足时失败需回退旧版（沿用现有失败路径）。
- 过渡期附件从四件增至五件，草稿比对与公开核对需覆盖 zip。
- 新客户端的 zip 路径要到下一版才会被真实公开更新使用；本版只能用单测、候选与本地模拟覆盖，验收记录须写明。

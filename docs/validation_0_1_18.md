## 3. 任务管理实际路径

`task_analysis_probe.py` 在上述优化 Tskmgr 上通过。使用自有进程身份及隔离笔记目录，不结束用户进程、不发起 UAC、不改用户现有笔记：

1. 默认进程树，搜索自有 PID，验证目标与祖先上下文同时可见。
2. 原生编辑器追加中文人工记录、依据及关注状态；JSON 接口读取同一记录。
3. agent 追加推测、来源及异常状态；旧版人工草稿提交被拒绝，草稿保留。
4. 重载 agent 历史，人工复核追加已处理状态；主视图 `status:resolved` 筛选显示目标及祖先。
5. 正常关闭重启，读取同一历史；切换应用范围，独立追加应用笔记，确认未覆盖本次运行历史。

截图在本地忽略目录目视审阅；界面字体跟随 DPI，笔记支持 Ctrl+S/Ctrl+A/Esc。当前工作站与优化构建的一条路径通过，不宣称物理混合 DPI、跨账户笔记同步或自动异常判定已验收。管理员授权、进程终止和 TCP 采集实现未改，复用 .17 的对应证据；笔记按执行账户隔离，JSON 接口只接受普通令牌。

本节为本地实现验证，最终交付见后文。使用说明及请求/错误格式见[任务分析](task_analysis.md)。

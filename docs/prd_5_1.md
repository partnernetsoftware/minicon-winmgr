# 后续与调研 · 当前能力缺口

> 稳定索引：5.1。上位：[PRD](prd.md)。更新：2026-10-16。旧调研见 [归档](archive/prd_5_1.md)，下表是候选需求，不是版本承诺。

| ID | 能力/缺口 | 当前事实与前提 | 排期 |
|---|---|---|---|
| FUT-01 | 物理混合 DPI、多屏热插拔 | 有每屏任务栏及 Run/通知面板局部 DPI 处理，不等于整套桌面已验收；需真实设备矩阵 | 未排期；0.1.6 仅解决设置窗口 |
| FUT-02 | 小时级稳定性 | 有资源采样与短轮次验收；0.1.5 的 100 次面板开关不等于长跑 | 未排期；记录基线、时长、句柄/GDI/内存走势与会话事件 |
| FUT-03 | UWP/宿主进程分组 | exe/pid 分组已有；宿主 exe 可能把不同应用误合并 | 未排期；先设计身份与回退规则、收集复现 |
| FUT-04 | 电源/IME 状态、通知兼容扩样 | 0.1.5 已交付真实应用图标与点击；声音/网络只有设置入口 | 未排期；逐项定义真实状态来源与交互 |
| FUT-05 | 可浏览桌面、拖放与系统上下文菜单 | 不在当前轻量任务栏主路径；需要明确文件操作与 Shell 集成边界 | 研究，禁止直接照旧草案开工 |
| FUT-06 | 全局 UI 可访问性与响应性 | 0.1.6 已实现设置键盘与布局；其他自绘控件语义、全局屏幕阅读器覆盖尚无验收 | 后续分模块推进 |
| FUT-07 | 悬停缩略图响应性 | 同步 PrintWindow 在消息线程，动态刷新和异常窗口需专项验证 | 0.1.6 先修开关与清理；重采样架构后续评估 |
| FUT-08 | 内存构成与长期走势专项 | 区分私有字节、私有工作集、共享页与缓存；按模块/场景归因，区分泄漏、缓存增长及正常波动；结合窗口/图标数量、预览与设置操作、会话事件进行小时级及更长采样 | 暂列 0.1.10 候选；交付可复现采样脚本、趋势图、增长归因及优化前后对照，不以单次工作集或强制修剪结果评价；当前继续推进 0.1.6 |

文件夹堆栈、隐藏开始菜单的搜索/最近使用已有代码；它们不是待建功能，也不因此恢复已退役的开始菜单按钮。通知区以 0.1.5 交付规格为准，不再安排第二次“基础点击转发”。

长期原则：companion 默认；外壳接管显式受控并可回滚；耗时操作不持任务栏/任务列表锁。线程模型按模块责任设计，不能把早期“不新增线程”复制为所有功能的永久限制。打包发布已有 workflow，签名与系统级 HKLM Shell 修改不在当前计划。

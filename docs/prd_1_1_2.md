## 1. 用户目标与现状

这里的 tray icon bar 指任务栏时钟旁的**通知区域图标**：用户能找到后台应用图标，通过点击或右键操作应用，并从“向上箭头”展开隐藏图标。

0.1.3 已有 `tray` 数据模型、`tray_host` 宿主注册和 `tray_bar` 绘制/事件转发基础。该代码基础不等于通知区域已完整可用：后续交付范围见[0.1.5 验收](archive/plan_0_1_5.md)，运行中通知宿主转换见[0.1.12 验收](validation_0_1_12.md)；实测不代表所有第三方应用均兼容。伴随 Explorer 时现有镜像是不可点击的降级占位，不能当作真实可用图标交付。

## 2. N1：应用图标生命周期

- 替换外壳模式下，应用能正常注册、更新及删除通知图标；只修改提示文字等部分字段时，不能丢失原图标或回调目标。
- 正常退出移除图标；异常退出后清理失效项。外壳重启后通知应用重新注册，并记录不响应重新注册的应用，不能宣称所有图标均可自动恢复。
- 图标身份、版本协商、隐藏状态及协议载荷兼容性先做真实应用探测；支持范围以实测结果列明，不以手工构造载荷单测代替系统调用链。
- 图标资源有明确所有权；显示、更新和删除不泄漏 GDI 资源，也不使用已经失效的外来句柄。

## 3. N2：显示与交互

- 已支持应用显示可辨认的真实图标和提示文字；点击、双击、右键能触发所属应用的实际动作。
- 区分应用协商的回调语义，防止重复激活、右键菜单一闪而过或坐标错误；未知/不支持项不能伪装可点击。
- 绘制、命中、回调使用一致快照，图标动态增删时不能点到邻居；弹出的应用菜单可正常获得焦点并关闭。

## 4. N3：隐藏图标面板

- 主条宽度受限时把溢出图标放入隐藏面板，不截掉或吞掉；有隐藏项才显示“显示隐藏图标”按钮。
- 点击按钮展开/收起；面板显示真实图标，具备与主条一致的提示和点击能力。再次点击、Esc、外部失焦可关闭，应用弹出的菜单不应被误关。
- 支持键盘到达按钮、进入面板、移动焦点及激活；提示文字可供识别。面板不超工作区，随目标屏 DPI 缩放。
- 本版先采用确定且稳定的可见/溢出排序；自定义钉住、拖拽排序及长期隐藏偏好不作为完成本版的前置条件。
- 设计基准：主条最多4个应用图标，按剩余空间缩减；点击格至少28 DIP。首次注册顺序稳定，更新不重排；协议隐藏项始终进入面板。
- 面板基准为4列32 DIP网格、8 DIP内边距、箭头上方6 DIP间隔；窄工作区缩减列数，高度不足时分页。按图标身份保持焦点，增删期间不能因数组下标变化误激活邻居。
- 提供通知区键盘入口（优先Win+B，被占用时用可用回退并说明）；面板方向键、Home/End、Tab、Enter/Space及Shift+F10可用。转交应用菜单后不抢回焦点，面板失焦处理须区分菜单与普通外部窗口。

### N3 补充：时钟合并入口（2026-10-15）

- 删除独立“通知”文字按钮与其占位；单击时间区域打开/收起完整通知面板。应用图标条紧邻时间左侧，隐藏图标箭头继续只展示隐藏项。
- 面板保留音量/网络设置，并加入“时间设置”。该入口与双击时间共用 `control.exe timedate.cpl`；双击仍直接打开时间设置，并收起首击弹出的面板。
- 时间设置使用原生可聚焦按钮，可 Tab 到达并通过 Enter/Space 激活。无应用图标/伴随模式也可访问；分页时保持时间设置与翻页按钮互不重叠，小工作区不能截掉新增行。
- Win+B 仍打开完整面板；此次修改不恢复已退役的开始菜单与列表入口。
- 0.1.10 新增“回收站 / Recycle Bin”原生按钮，与时间设置并列，音量/网络在首行；分页导航另占一行。点击打开系统回收站浏览窗口，沿用后台启动及明确的失败提示；不提供清空操作。布局单测、中英文按钮的真实目录打开已通过；0.1.12 补中英 × 明暗 × Enter/Space 八组回归，结果见[验收记录](validation_0_1_12.md)。

### N6 补充：桌面设置入口（0.1.21，主线开发中）

- 面板新增“桌面设置 / Desktop settings”原生按钮，位于时间设置/回收站行之下、分页行之上，左列；分页行整体下移一行。
- **伴随模式**（Explorer 仍是外壳）：按钮打开 Windows 个性化“背景”页（`ms-settings:personalization-background`，回退 `control.exe /name Microsoft.Personalization /page pageWallpaper`），壁纸与颜色由系统处理；Minicon 不绘制桌面。
- **替换模式**（Minicon 是外壳，Explorer 桌面宿主已关闭）：按钮打开系统颜色选择框，确认后保存 `desktop.color` 并立即由 Minicon 绘制纯色桌面。这是唯一由 Minicon 绘制的桌面内容。
- 纯色桌面实现：一个无边框、不激活的 `WS_POPUP` 窗口，铺满虚拟屏幕，层级在所有应用窗口之下；只持有一把纯色画刷，不持有位图、不创建线程。显示器变化时重新铺满；未设置颜色时不创建窗口，行为与之前一致。
- 任务栏的全屏让位判断把该窗口视为桌面宿主，不会因它铺满屏幕而让任务栏退到底层。
- 清除颜色：“桌面设置”对话框的“清除”按钮把颜色设为未设置（0.1.26 起；0.1.25 缺此按钮，已修正）；颜色与图片都未设置并确定后，桌面窗口隐藏。图片壁纸、桌面图标与右键菜单不在本版范围，见 [0.1.21 计划](archive/plan_0_1_21.md)。
- 0.1.22 修复：颜色选择确认后保存失败的缺陷（设置写入白名单遗漏 `desktop.color`）已修复；白名单判定有直接单测，私有桌面测试覆盖“先保存、后出现”的路径。
- 验收：配置解析与往返、颜色通道顺序、面板布局、任务栏桌面宿主排除均有单测。实机验收（替换模式下颜色即时出现、显示器变化、Win+D 与显示桌面按钮、伴随模式不绘制）待执行，未通过前不声称交付。

### N7 补充：替换模式图片壁纸（0.1.23，计划中）

- 目标：替换模式下，用户可在“桌面设置”中选择一张图片作为桌面背景。伴随模式仍由系统个性化页面处理，本节不改变伴随模式。
- 显示优先级：有可用图片时绘制图片；图片缺失、损坏或格式不支持时回退到纯色（`desktop.color`）；都没有时不创建桌面窗口，行为与 0.1.22 一致。
- 配置：新增 `desktop.wallpaper`，保存图片的绝对路径；空值表示清除。路径失效不删除配置，只在下次尝试绘制时记录日志并回退，避免移动文件后静默丢失设置。
- 交互（0.1.25 修订）：替换模式下“桌面设置”打开一个对话框，包含：颜色（“选择颜色…”按钮与当前颜色值，可“未设置”）；背景图片（下拉列表，首项“无图片”，其后为系统自带壁纸，即 `%SystemRoot%\Web\Wallpaper` 下的 jpg、jpeg、png、bmp，最多列出 300 项；列表中仅列名称，不加载缩略图）；“浏览…”（系统打开文件对话框，选中的图片加入列表并选中）。按“确定”应用并保存，“取消”不改变设置；颜色与图片都未设置时，桌面窗口隐藏。
- 对话框是模态的，只有一个窗口，关闭即释放控件；不常驻图片列表以外的资源。0.1.24 之前的“是/否/取消”提示框已废弃。
- 已知待改进（计划于 0.1.26）：0.1.25 对话框的视觉风格与设置面板不统一，需按主题、字体、DPI 与可访问性做 UI/UX 设计，功能不变。
- 内存约束：不常驻整屏位图，不常驻解码结果，不使用 Direct2D/D3D 设备。绘制采用分段解码：解码器输出到屏幕尺寸，每次复制一段（约 32 行）到小缓冲，画到窗口后复用缓冲。峰值目标约 1 MiB，以原型实测为准。
- 大图保护：源图像素数超过上限（上限在原型阶段确定）时拒绝解码并回退，防止单次绘制耗时或内存失控。
- 绘制时机：仅在窗口显示、尺寸变化、显示器变化等系统要求重绘时执行，不使用定时器重复解码。
- 缩放方式：本版采用铺满屏幕并保持比例、居中裁剪；多种拉伸或平铺模式不在本版。
- 验收：原型测得峰值内存与单次绘制耗时（1080p 与 4K 各一张）；私有桌面测试覆盖“选图 → 绘制 → 文件缺失回退”；与纯色路径的回归；候选层回归。

## 5. N4：系统图标与伴随模式边界

- 音量、网络、电源与输入法状态分开核查：哪些由当前系统提供、哪些需要独立实现，先形成支持表；不能假设它们都会作为普通应用图标注册。
- 音量、网络至少提供明确命名、可打开对应系统界面的入口。若使用入口而非实时状态图标，界面和文档须明确区分，不能用固定假图标暗示已实现状态监控。电源/输入法缺口逐项登记。
- 伴随模式保留 Explorer 对通知区的所有权，不抢占其宿主或伪造可用镜像。0.1.5 的完整通知图标交互以替换模式为验收重点；伴随模式的限制应明确可见，是否保留占位在设计阶段决定并回写。
- 不以修改默认关联、自动接管外壳或关闭其他应用来掩盖兼容性问题。

## 6. N5：可靠性与验收

- 枚举/回调失败不得阻塞任务栏消息线程；未知消息与不支持载荷有可定位日志，日志不刷屏。
- 对图标增删更新、溢出展开收起及应用退出做重复测试，记录句柄/GDI趋势和响应；性能基线用同模式、同应用数量比较。
- 真实 GUI 验收覆盖探针程序和实际应用，记录系统版本、应用版本、宿主/伴随模式及失败分支。成功标准是图标可见且动作到达应用，不只是注册函数返回或消息已发送。
- 高 DPI、小工作区、多屏及菜单焦点分别验证；缺设备条件标为未验证，不把算法测试写成实机通过。

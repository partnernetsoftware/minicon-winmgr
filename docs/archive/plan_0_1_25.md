# 0.1.25 计划：桌面设置对话框（颜色与背景图片）

状态：已公开（2026-10-27，v0.1.25 Latest，tag v0.1.25）。验收证据见 [validation_0_1_25.md](../validation_0_1_25.md)。需求见 [prd_1_1_2.md](../prd_1_1_2.md) §N7 的“交互”条目。

## 1. 原因

0.1.23 的交互是“是/否/取消”提示框再接一个单独的选择框，用户体验差。0.1.25 改为一个对话框，颜色与背景图片在同一处设置，并支持系统自带壁纸与用户自选图片。

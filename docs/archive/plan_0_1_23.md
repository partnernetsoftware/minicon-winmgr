# 0.1.23 计划：替换模式图片壁纸

状态：已公开（2026-10-27，v0.1.23 Latest，tag 281a3dd）。验收证据见 [validation_0_1_23.md](../validation_0_1_23.md)。需求回写见 [prd_1_1_2.md](../prd_1_1_2.md) §N7。上一版 [0.1.22](../validation_0_1_22.md) 已公开。采样证据讨论稿顺延为 [0.1.26](../plan_0_1_26.md)。

## 1. 目标

替换模式下，在“桌面设置”中可以选择一张图片作为桌面背景，常驻内存增加接近零。内存方案依据见 PRD §N7：不依赖 Explorer，不常驻整屏位图，不引入 GPU 设备。

## 2. 任务树

## 3. 验收门槛

- 峰值内存：原型实测值写入验收记录；若超过约 4 MiB，需先说明原因再进入实现。
- 单次绘制耗时：1080p 与 4K 各一次，记录数值；超过上限的图片回退纯色，不阻塞消息线程过久。
- 与 0.1.22 纯色路径相比，不增加其他常驻资源。

## 4. 不做

- Progman/WorkerW 技巧、系统壁纸接口的替代绘制（替换模式下没有宿主绘制，无效）。
- Direct2D/D3D 显存方案（设备初始化的常驻成本未知，留作备选）。
- 多种拉伸、平铺、幻灯片、按显示器不同图片。
- 桌面图标与右键菜单。

## 5. 原型实测

在仓库内的测量用例（忽略的原生测试，源图为系统自带 4K 壁纸 `img0_3840x2160.jpg`，808 KB）：

| 目标 | 单次绘制 | 工作集变化 | 私有内存变化 |
|---|---|---|---|
| 1920×1080 | 约 100 ms | 约 8.3 → 10.1 MB（含首次加载 WIC 组件） | 约 1.68 → 1.92 MB |
| 3840×2160 | 约 129 ms | 约 10.2 → 10.2 MB | 约 1.92 → 2.11 MB |

补充数据点（子代理在临时副本中测得，源图为 1920×1200 的系统壁纸）：1920×1080 约 174 ms；3840×2160 约 645 ms，放大源图的耗时明显高于缩小。因此实际使用时应按屏幕尺寸解码，避免放大。

结论：峰值像素缓冲约 0.5 MB（32 行 × 3840 宽 × 4 字节），私有内存增加约 0.2 MB，常驻为零。满足 §3 的门槛，无需额外说明。

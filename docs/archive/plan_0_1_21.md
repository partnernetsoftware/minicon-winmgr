# 0.1.21 计划：时钟通知面板的桌面设置（纯色）

状态：已公开（2026-10-27，v0.1.21 Latest，tag 7e387ed）。验收证据见 [validation_0_1_21.md](../validation_0_1_21.md)。需求回写见 [prd_1_1_2.md](../prd_1_1_2.md) §N6；配置键见 [prd_6_1.md](../prd_6_1.md) §6 的 `desktop.color`；交互表见 [prd_4_1.md](../prd_4_1.md) §4。上一版 0.1.20 已公开（[验收](../validation_0_1_20.md)）。原采样证据讨论稿顺延为 [0.1.24](../plan_0_1_24.md)。

## 1. 用户问题与目标

用户希望在点击时间弹出的菜单里设置桌面外观，先做纯色。Minicon 替换外壳后，Explorer 的桌面宿主关闭，桌面背景无人绘制；系统个性化页面在替换模式下改了也看不到。目标：替换模式下，Minicon 自己绘制一块纯色桌面，且保持稳定、低内存（一个窗口、一把画刷，不持有位图、不起线程）。伴随模式保持交给 Explorer 与系统个性化页面。

图片壁纸、桌面图标、右键菜单不在本版。

## 3. 实施约束

- 不新增位图、线程或常驻采样；窗口只持有一把纯色画刷，颜色变更时替换画刷并释放旧画刷。
- 只在 `is_self_shell()` 为真时绘制；伴随模式不创建该窗口。
- 颜色选择框是模态对话框，打开前先隐藏通知面板，避免面板失焦后重复收起。
- 任务栏、通知面板等既有 TOPMOST 窗口仍在其上；该窗口不激活、不进任务栏。

## 4. 测试与停止条件

| 风险 | 最小验证 | 状态 |

| 配置非法值、空值清除、往返 | `every_settable_key_round_trips_in_both_directions` 扩展 | 通过 |
| 面板新增一行导致截断或与翻页重叠 | `scaled_grid_and_footer_stay_inside_small_work_areas` | 通过 |
| 铺满屏幕的窗口被任务栏全屏让位误判 | `is_desktop_host_class` 包含该窗口类 | 通过 |
| 静态日志、格式、文档边界 | 质量门禁、`cargo fmt --check`、`check_public_docs.py` | 通过 |
| 实机：颜色即时覆盖、显示器变化、Win+D/显示桌面 | 隔离桌面探针 | 未做 |

已知与本版无关的失败：`settings_panel::tests::native_focus_and_escape_remain_responsive_during_two_second_save` 在未修改的 HEAD 上同样失败，属于本机桌面焦点环境问题，记录待查，不计入本版通过项。

## 5. 备选与不做

- 图片壁纸：需要解码与位图常驻或重复解码，内存与 CPU 成本高，另立版本评估。
- 清除颜色的界面入口：本版通过 `winmgr.cnf` 的 `desktop.color` 空值实现，界面入口待定。
- 直接写注册表或调用 `SystemParametersInfo` 设置壁纸/颜色：会绕过系统广播且替换模式下无宿主绘制，不采用。

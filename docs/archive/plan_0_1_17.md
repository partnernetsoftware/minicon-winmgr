## 1. 目标

保留普通权限“我的任务”，由用户主动打开“所有用户与系统任务”并授权。Winmgr 主体保持普通权限，管理员工具关闭即结束该次管理。网络增强按数据来源与开销验证结果选择，不以不能兑现的实时流量承诺阻塞权限边界交付。

## 3. 边界与完成条件

不承诺管理员可任意操作受保护进程，不把其他用户切换或注销当作结束任务的附带行为。不安装常驻特权服务、不创建通用管理员命令通道。权限结果、目标身份和取消语义按[跨平台服务原则](../prd_7_2.md)可结构化表达，避免把 UAC 弹窗或 Windows 令牌写成跨平台接口的唯一模型。防火墙、连接干预、优先级/服务控制和进程树批量结束均需另行立项，不随入口自动交付。

UAC 验收分次说明当次授权目标，不要求用户记住交替的 Yes/No 顺序，也不自动点击安全桌面。跨账户真实环境未覆盖时须明确记录，不能以同账户管理员测试替代。

双入口在准确候选上完成真实授权与取消、身份及退出验证，再进行公开交付。网络速率仅在数据与开销专项通过时列为已交付，否则从本版范围明确移出；后续去向见[路线](../roadmap_0_1.md)。

## 网络数据源评估起点（2026-10-20）

微软的 [GetPerTcpConnectionEStats](https://learn.microsoft.com/en-us/windows/win32/api/iphlpapi/nf-iphlpapi-getpertcpconnectionestats) 提供 IPv4 TCP 单连接扩展统计，IPv6 使用对应接口。动态传输统计须先启用采集，启用需要提升后的管理员权限；读取成功仍必须检查 `EnableCollection`，未启用时不能使用返回计数。该接口不能直接代表包含 UDP 和短连接的完整进程流量。

评估起点仅确认 API 约束；后续实际 TCP 计数和权限实验见下文。本版选择交付端点增强，完整速率和持续开销专项递延，未将 API 调用成功当作流量能力验收。

本机普通用户只读探测：建立自有 IPv4 loopback TCP 连接并实际传输数据，从真实 TCP 表定位连接，读取 `TcpConnectionEstatsData` 的读写配置成功（状态 0），但 `EnableCollection=false`。没有调用启用/禁用接口，也没有使用或声称得到流量计数。这个结果证明“读取调用成功”不足以提供速率；该首轮普通令牌观察不能证明管理员能力；后续管理员计数实验见下文，IPv6 计数及持续开销仍未验证。

## 启动身份契约

管理员角色在工具入口、任何实例复用之前校验真实提升令牌。启动参数只传身份引用，不相信参数中自称的用户 SID；通过一次性本地命名管道的内核 server PID，核对发起进程的 PID/创建时间、令牌 SID 和会话。管道限制原用户及 Administrators、拒绝远端，随机名称且拒绝既有实例。交接只用于启动身份核实，不传任意管理命令；管理员窗口启动后关闭交接句柄，不保留特权服务或控制通道。

原用户与执行账户分别记录；另一管理员账户凭据不能覆盖原用户身份。原发起进程退出、身份改变或跨会话时明确失败，不猜测“当前用户”。普通/管理员角色、原用户、执行账户及会话必须进入实例隔离依据。真实同账户 UAC 批准/取消及跨账户令牌验证见验收记录；另一账户凭据输入界面未覆盖，不把普通管道组件测试作为授权证据。

## 开发进度：身份与后端上下文

已增加原用户/执行账户/会话/角色数据及真实令牌授权对象，管理员构造入口要求实际提升，调用身份由启动管道的内核对端 PID 加创建时间及进程令牌核实。只读组件测试确认正常本地对端、错误创建时间和非法引用处理；普通上下文不能获得管理员角色。

采样器可接收显式授权上下文；普通范围按原用户 SID 过滤，管理员范围保留可查询的所有账户及不可访问条目的真实元数据。无法获得创建时间的行单独返回，不伪造可管理身份；所属用户不可读为缺失值。管理动作接收同一上下文，复核创建时间并按范围检查真实权限，原普通接口保持仅管理本人。

已接入 Winmgr 与工具内的管理员入口，通过 Windows `runas` 启动独立工具；批准后等待窗口就绪，取消返回明确结果。实例按角色、原用户、执行账户和会话隔离，筛选、网络视图与已核实的目标身份可交接。列表增加所属用户和会话，并按归属组织；没有创建时间的受限行只展示元数据，管理按钮禁用。关闭和结束操作均拒绝系统关键进程。

本地格式、严格 Clippy 和相关身份/视图单元通过；普通工具的自有目标结束/取消及正常关闭已做定向原生验证。候选工作流增加现有管理员令牌组件验证、一次自有 TCP 连接能力观察，以及仅在一次性 hosted Windows runner 上创建并清理标准账户的跨账户身份验证。这些组件结果不能替代真实 UAC 批准/取消，也不代表测试过凭据输入界面。

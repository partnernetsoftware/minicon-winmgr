## 产品定位：稳定优先，简约常驻

核心卖点是稳定，内存安全与低内存占用是其中的工程支撑；简约同时指界面克制与可选能力不产生无谓的默认开销。对外说明以可核验事实为依据，不承诺零崩溃、零泄漏或所有环境固定内存值。

“用不上的可选功能，默认不加载”是本轮设计要求。0.1.7 基线中，缩略预览关闭时不创建窗口，通知宿主按外壳身份/显式配置决定初始化；旧菜单默认关闭入口但仍初始化隐藏 UI。0.1.8 进一步跳过默认关闭的旧菜单初始化，并延迟 Run 窗口与工作线程的创建。

P0 实施：先盘点可选模块的窗口、线程、扫描、缓存与计时器；明确关闭时不初始化哪些资源、启用时如何按需创建、关闭后释放哪些资源。优先收敛默认关闭的旧菜单；已有 Run/设置等日常路径按交互需要评估，不把“简约”解释为一律禁用必需能力。记录默认启动与首次启用的资源和响应差异，开发期只跑相关模块与桌面层。本轮已实现旧菜单默认跳过初始化，并进一步让 Run 的窗口与工作线程延迟到首次召唤；已发布 v0.1.7 保持不变。

README 中内存数字来自 v0.1.7 release 的特定短时采样，区分私有字节与工作集。长期增长与模块归因仍留在 FUT-08 / 0.1.10 候选，不用单点数据宣称“极低”或无泄漏。

## 建议主线：日常操作的确定性

优先把窗口切换、运行命令和修改设置这三条路径磨顺。以下为前期设计方向，具体交付范围以文末 W18-1 至 W18-4 为准。

| 顺序 | 用户场景 | 设计候选 | 完成标准 |
|---|---|---|---|
| P1 | 窗口很多，在横栏和竖栏之间切换 | 统一悬停、键盘焦点、当前窗口与分组状态；长标题/溢出优先保证可辨认，避免增加常驻按钮 | 四边均能区分当前/选中/悬停；鼠标与键盘完成同一任务，切换不抢走当前应用焦点 |
| P2 | 在 Run 中找回命令或打开路径 | 优化历史/路径候选的信息层级、选中与执行反馈；核查中英文文案和长路径显示 | 能区分候选来源；采用候选与执行动作明确；失败保留输入并给出可操作反馈 |
| P3 | 调整设置后确认是否生效 | 核查即时生效、下次启动、环境只读与保存状态的表达；继续调整对齐和焦点细节 | 默认窗口无需滚动即可完成日常设置；较窄窗口无重叠，焦点项可见；说明随状态出现 |

已按真实反馈收敛为 W18-1 至 W18-4，并纳入实时建议、任务管理器激活和设置文案修整。

## 保持的边界

- 设置仍是唯一配置入口，不恢复已退役的开始菜单或窗口列表按钮。
- English 默认，中文完整支持；明暗/自动主题与四边位置沿用，不另起视觉体系。
- 不因方便启动而主动申请 UAC；已提升时降权的规则沿用。
- 当前讨论不加入桌面文件浏览、拖放、第二套启动器或大规模架构改造。
- 内存构成与长期走势仍属 FUT-08，暂列 0.1.10 候选；短时资源数据不能代替该专项。

## 讨论焦点与验证

本轮验证任务栏识别/切换、Run 候选体验和设置状态表达。每个切片开发期只跑相关层；准备下一次发布时执行完整 release 层。物理多屏/混合 DPI、屏幕阅读器和长跑需要单独环境，不把计划写成已覆盖。

## 本次实施范围与验收约定

| 切片 | 行为与 UI/UX | 验收 |
|---|---|---|
| W18-1 按需启动 | 默认不初始化旧菜单；Run 只注册快捷键，首次召唤才创建窗口、三个有界工作线程及轮询计时器；关闭复用草稿/历史，不反复创建 | 冷启动无旧菜单/Run 窗口；首次快捷键成功；第二次复用同窗口；显式旧菜单开关兼容；启动/首次使用资源实测 |
| W18-2 任务栏确定性 | Home/End 到首尾，Space 与 Enter 一致；Esc 返回召唤前窗口；键盘浏览时保留原活动窗口标记，选中框独立 | 四边键盘动作与溢出可达；Esc 恢复原窗口；失效句柄安全忽略；鼠标仍保持激活/最小化语义 |
| W18-3 Run 候选反馈 | 展开时显示简短键盘提示；选中候选时主按钮显示“采用/Use”，采用后恢复“运行/Run”；空输入也可采用历史候选 | 采用不执行；再次确认才执行；候选/错误不覆盖用户输入；双语、明暗截图及回归 |

不新增常驻入口、运行时重载系统、大型依赖或更新器。0.1.9 的 Check / Update / Restart 单独设计，参考 minicon。先执行相关模块/桌面专项，发布前完整 release 层；完成 GitHub Release 后验证可下载附件与 SHA256SUMS。

### 视觉与状态补充

Run 候选区展开且选中时，主按钮为 Use / 采用，顶部显示键盘提示；采用后收起候选并恢复 Run / 运行，不执行。空状态区不占高度，实际进度/错误出现时才展开，并保持可选择复制。保留原生命令输入、历史来源标签与路径水平滚动。

任务栏：活动窗口使用强调色边条，键盘目标使用细框，悬停文字提高亮度；键盘浏览时活动边条仍代表召唤前的应用，Esc 交还焦点。Home/End 包含末尾溢出入口；Space 与 Enter 使用同一激活逻辑。

Run 关闭后复用窗口和 worker，以保留草稿与历史、避免反复创建；按需初始化针对首次使用前的默认开销，不宣称关闭后全部卸载。三个自有 worker 之外，Win32/COM 可能创建额外线程，验收记录进程实际线程数而不承诺仅增加三个线程。

### 追加：实时建议与任务管理器激活

- Run 输入停顿约 150 ms 后在下方更新建议；历史、本地路径、开始菜单应用分别标明来源。两行原生 ListBox 项，主行显示命令/名称，次行显示来源/完整值，采用当前主题的选中细框与背景。保留完整原生文本供键盘和辅助技术读取。最多 20 项、最多 6 个可见行；空间不足时优先保留输入、错误和操作按钮。
- 应用发现仅首次输入至少两个字符的单个应用名时在 Run worker 执行；只扫描本地固定盘上的开始菜单，限制 200 ms / 4096 条目 / 12 层，缓存本次结果。不扫描整个磁盘，不联网，不在启动时扫描。参数、网址、环境变量与路径输入不触发应用发现。
- 修复设置及配置详情注册窗口类时宽字符串临时值指针失效的问题，保持字符串活到 RegisterClassW 返回。
- 已复现任务管理器最小化后 ShowWindow / ShowWindowAsync 错误 5，但 SetForegroundWindow 返回成功且仍处于 iconic 状态。标准 WM_SYSCOMMAND / SC_RESTORE 实测可恢复；直接 show-state 被拒时投递目标窗口的标准命令，最小化采用对称后备。仍以普通权限运行，不改系统策略或权限。

依据：[WM_SYSCOMMAND](https://learn.microsoft.com/en-us/windows/win32/menurc/wm-syscommand)、[ShowWindowAsync](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-showwindowasync)、[SetForegroundWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow)。实际成功条件为前台句柄正确且不再最小化，不能只相信 API 返回值。真实任务管理器专项只操作当前会话既有窗口，不主动启动或请求 UAC。

- 设置标题采用构建版本：Settings — minicon-winmgr 0.1.8 / 设置 — minicon-winmgr 0.1.8，语言切换后同步刷新。
- 路径建议复用 Run 的环境变量展开规则，未知变量保留；采用前保持原输入，采用后使用完整路径并按需引号包裹。应用建议的 200 ms 是枚举间检查的工作预算，不宣称能中断底层文件系统调用。
- 首页文案围绕“少些打断，多些专注”，介绍产品与稳定、轻量、简约的关注点；保留语言/下载入口与截图。技术细节和采样口径放在完整中英文 README。

- 日常设置不显示环境变量名称或配置来源；被启动配置固定的选项仅说明不可修改，完整技术来源保留在“配置与关于”。

## 产品范围与交互

保持默认英文、中英双语、白天/黑夜/自动主题、紧凑暖色设置及四边停靠。不新增默认联网、遥测或常驻诊断，不主动申请 UAC。

| 能力 | 最终行为 |
|---|---|
| 左右侧栏宽度 | 拖动朝桌面的 6 DIP 内边缘预览，松开后一次异步保存。默认 180 DIP，160–480 DIP 且不超过所在屏幕跨度三分之一；按 DPI 换算。Esc、失去捕获或换边取消，不提交中间值。 |
| 用户偏好 | 默认 `~/winmgr.cnf`；无参数启动加载。新文件不存在时兼容旧程序旁设置，首次成功保存迁移，旧文件保留。环境覆盖优先，未知键与手写注释保留；文件大小有界、备份、失败保留原文件并可重试。细表见[配置规格](../prd_6_1.md)。 |
| 最大化贴边 | 侧栏预留从完整显示器边界计算，避免继承旧底部缩减。原工作区仅用于退出恢复；有 AppBar broker 时继续协商。SPI 失败不写入虚假成功状态。 |
| 回收站 | 点击时钟的小面板提供入口；2×2 常用按钮，分页按钮另行布局。中英/明暗、Tab 和 Enter/Space 可用；显式打开回收站命名空间，不操作内容。 |
| 跨版本启动 | 同用户/会话发现不同 exe 摘要时询问，默认取消，Esc 取消。确认后正常关闭已核对 PID/句柄的原进程，最多等 15 秒，不强杀、不提权、不修改登录 Shell；同摘要复用。兼容 0.1.4；无法查询旧版版本时只显示真实路径，不猜版本。 |
| 交接失败 | 原进程拒绝退出则给出错误；新界面普通初始化错误/展开时尽力恢复原文件。就绪后撤销回退；不新增 watchdog，不承诺崩溃/断电自动恢复。 |
| 可选诊断 | “配置与关于 → 诊断”；明确开始后才创建采样，5 秒一次，最长 8 小时/5762 点。停止、关闭或到上限释放数组，保留固定摘要；替换前默认否。导出展示字段范围，允许取消，只包含白名单数值。 |

## 资源与稳健性设计

| 对象 | 已实现约束与核验方向 |
|---|---|
| 预览 | 单个 DWM 合成关系替代 UI 同步 PrintWindow，换目标/隐藏/销毁时释放；默认关闭。停滞源窗口不能造成无限线程或卡住任务切换。 |
| 窗口图标 | 一个固定 worker、最多 256 窗口，pending/ready 各一份，通知合并；12ms 查询及 64ms 批次预算，过期结果丢弃。owned 32px 图标共享至最后引用后释放。路径缓存 64 项/256KiB key 预算。 |
| 日志 | 512 槽有界队列、单条 16KiB UTF-8 上限、4×8MiB 文件预算。静态文案及数值/布尔字段，文本、路径、panic 与 Debug 链屏蔽。 |
| 更新 | WinHTTP 原生异步、16KiB 流块、64MiB exe/512KiB API/64KiB 校验和上限、整个操作预算与取消检查。callback context 在 HANDLE_CLOSING 才最终释放；流式哈希/PE 校验/拷贝，不保留整份 exe 缓冲。 |
| 后台交付 | 只保留最新进度及一个不阻塞的终态；隐藏设置不丢终态，退出发取消、不在 UI join。交接清单 16KiB+1 读取保护，取消时保留旧文件。 |
| 其他边界 | native 文件 I/O 和部分图标提取仍非可强制取消，不能承诺所有路径硬实时；完整所有权与剩余故障矩阵见[资源审计](resources_0_1_10.md)。 |

每项优化要说明原因、资源所有者/上限、相应证据。不得以强制修剪工作集或减少默认功能制造优化数字。Rust 类型安全不替代 Win32 句柄生命周期验证。

## 测量协议与证据边界

外部采样绑定同一进程句柄、创建身份及 exe SHA，默认 5 秒记录 Private Bytes、Working Set、可用时的 Private Working Set、句柄/GDI/USER/线程及观察器开销；进程退出即停止，不跟随复用 PID。Private Bytes 不等于物理驻留量，Private Working Set 不支持时留空。

场景包含空闲、设置/主题/语言切换、窗口生命周期、图标 churn、预览、更新失败/重试与静置回收。受控对照使用相同机器、优化配置和功能开关，三次全新进程交替顺序；窗口 300 次、设置 200 循环，预热 5 分钟、操作期、回收 10 分钟。按实际采样核对中位数/P95/峰值/阶段趋势及覆盖率，不补造等距点，不把组件差值当整应用改善。

原始 JSON/CSV、恢复路径及诊断日志保存在忽略的 target。公开摘要仅含审阅后的白名单数值、条件与二进制身份；图片目视检查后入库。公开材料不能含工作站绝对目录。

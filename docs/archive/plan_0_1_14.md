# 0.1.14 计划：显示桌面与按需管理员运行

归档：2026-10-20，已被公开 .15 替代；以下保留当时的交付事实与限制。

状态：已合 main 并公开发布为 Latest；准确候选桌面、真实 UAC 分段和公开 .13 → .14 更新验收完成。一次交互测试退出超时尚未定位，作为已知限制保留并跟踪。更新：2026-10-19。

当前公开版为 [v0.1.14](https://github.com/partnernetsoftware/minicon-winmgr/releases/tag/v0.1.14)。交付范围、失败历史及覆盖限制见[0.1.14 验收记录](../validation_0_1_14.md)。

## 1. 版本目标

补齐两个直接影响日常使用的小功能：一键显示桌面，以及从 Run 明确选择以管理员权限运行目标。Winmgr 自身始终按现行规则以普通权限运行；只有用户勾选并提交的目标走 Windows UAC。

本版保持现有 Run 按键规则。上下键继续预览候选，首次 Enter 采纳、再次 Enter 执行，Esc 撤销预览等行为仍以 [Run R1–R7](../prd_1_1_1.md) 为准。新复选框只扩展本次提交的权限选择，唯一行为规格为 [R8](../prd_1_1_1.md#10-r8显式选择管理员运行)。

## 3. 功能边界与完成条件

| 分支 | 具体行为与完成条件 |
|---|---|
| A 显示桌面 | 横向时钟右侧、竖向底部时钟旁显示器图标；竖向日期时间分两行。单击异步请求最小化当前虚拟桌面各显示器的应用窗口，包含 Winmgr 设置；保留桌面、任务栏和工具窗。重复点击继续最小化，不切换为还原。被系统或应用拒绝的请求不提权、不阻塞 UI。准确 CI 候选实测通过，范围与限制见验收记录。 |
| B1–B2 选择与生命周期 | 原生“使用管理员权限运行”复选框，默认未选；从隐藏状态重新呼出复位为未选，不持久化到配置或历史。候选预览、采纳、浏览历史和编辑命令不改变选择。键盘可聚焦/切换，文案适配中英文与明暗主题，IME 及现有焦点规则保持。 |
| B3 启动路径 | 每次明确提交同时快照命令和权限选择，交给现有有界 worker；复用 `shell_launch` 的解析、参数、环境变量、工作目录及 Explorer 保护。普通分支保持原行为，管理员分支只对目标发起系统 UAC。不支持提权的目标明确反馈，不静默改为普通运行；其他入口不自动获得提权能力。 |
| B4 完成与错误 | 勾选本身不执行；提交中防重复运行。系统接受请求后才按现有规则关闭并写成功历史，不宣称外部应用已完成工作。UAC 取消显示“已取消授权”，取消/失败不写成功历史，保留命令、选区与修正入口。结果按请求代号匹配，关闭、隐藏、重开后的旧结果不覆盖新状态；不承诺能撤回已经交给系统的启动。 |
| B5 验证 | 覆盖默认未选、复位、键盘操作、候选/草稿保持、含空格路径及参数、重复提交、过期结果和失败反馈。真实 UAC 接受后核对目标权限、Winmgr 仍为普通权限；真实取消后确认没有目标启动和成功历史。控件 fixture 与模拟结果不能替代真实 UAC。 |

启动技术边界：Winmgr 自身的管理员入口仍走 0.1.13 已修复的 WinAPI 降权；Run 的显式目标提权由统一启动模块调用系统 UAC。两条路径分别验收，不能因为外壳降权验证通过，就认为目标提权也已完成。

## 4. 执行顺序与依赖

1. B1–B2：先落地控件和生命周期，确认新增焦点顺序与现有 Run 规格兼容。
2. B3–B4：接入请求快照、统一启动模块与结果处理；保留普通分支回归，防止修提权时破坏现有运行。
3. B5：先运行隔离控件与故障测试，再做真实 UAC 接受和取消验证。其余工作自主推进；需要安全桌面授权操作时明确停下，由用户操作。
4. C：用最终范围生成准确 CI 候选，完成同文件桌面和旧版本更新/回滚验收；不拿此前仅含按钮的开发 exe 代替完整候选。
5. D：验证通过后收尾合并和发布；公开附件复用已验收候选，公开后再验证真实 .13 更新器。D3 完成后才将本版标为交付完成。

## 5. 回归与发布检查

- 源码检查按仓库现有流程执行 fmt、严格 Clippy、语言/并发单元矩阵和适用故障层；与新增控件和启动结果有关的专项单独记录。
- 桌面验收同时覆盖两个功能，以及原有 Run、设置、通知区和更新路径。原生输入/IME、设备环境与人工操作按实际覆盖记录，不把模拟消息写成完整真实输入验收。
- 更新先验证公开 .13 基线到候选及失败回滚，核对实际进程路径、版本、普通权限和就绪回执；保留原文件名。每轮结束恢复原实例、工作区与 Shell 设置。
- 发布前确认 main 和发布工作流成功，三个附件与准确候选一致；公开后检查 Latest、非草稿、非预发布，并以真实公开 .13 更新器完成 .14 下载、校验、重启和回执。
- 发布完成后更新 README、PRD、文档索引与验收摘要；将已被替代的 0.1.13 计划归档并修正引用。0.1.14 计划在本版有效期间保留当前入口。

## 6. 留待后续讨论

本版不安排 Run 整体交互重做，不改变单次/两次 Enter 模型，不增加联网搜索、全盘索引或新的命令语言。原五条任务走查和模型比较完整保留在[Run 交互讨论档案](design_0_1_14_run_interaction.md)，尚未决定新的按键规则，也不自动指定下一个版本号。

旧启动器后台化、pin/recents 存储迁移及剩余容量边界仍保留在[原维护备选草案](plan_0_1_15_maintenance_draft.md)；性能备选、物理多屏/混合 DPI、无障碍与长期资源观察按原记录维护，不因本版列任务树就自动扩大实施范围。

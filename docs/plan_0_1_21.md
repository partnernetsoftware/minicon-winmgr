# 0.1.21 计划：时钟通知面板的桌面设置入口

状态：开发中（main 分支，未打 tag、未公开）。需求回写见 [prd_1_1_2.md](prd_1_1_2.md) §N6；交互表见 [prd_4_1.md](prd_4_1.md) §4。上一版 0.1.20 已公开（[验收](validation_0_1_20.md)）。原 0.1.21 采样证据讨论稿顺延为 [0.1.22](plan_0_1_22.md)。

## 1. 用户问题与目标

用户希望在点击时间弹出的菜单里直接进入桌面外观设置，主要用于设置桌面颜色或壁纸。目标是增加一个入口，同时保证稳定和低内存占用：Minicon 不自行实现图片选择、预览或壁纸缓存。

## 3. 实施约束

- 不新增常驻窗口、位图、线程或图片缓存；按钮随面板重建，与既有按钮同生命周期。
- 启动沿用 `shell_launch` 后台执行与失败提示，不在消息线程阻塞。
- 替换模式下桌面由 Minicon 接管、无 Explorer 桌面宿主绘制背景，系统保存的壁纸或颜色不会即时可见；该限制须在说明与验收中明示，不以此声称壁纸已生效。

本版不声称实机壁纸或颜色已写入并显示；只有上表的真实桌面验收完成后才能标记为交付。

## 5. 备选与不做

- 应用内置壁纸选择器（图片预览、缩略图缓存）：内存与稳定性成本高，本版不做；如需要，另立版本评估。
- 直接修改注册表或调用 `SystemParametersInfo` 设置壁纸或颜色：会绕过系统的验证与广播行为，不在本版采用。

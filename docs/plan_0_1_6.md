# 0.1.6 版本计划 — 设置日常可用与反馈闭环

> 起草：2026-10-15 · 基线：0.1.5 / `2f1a470`。
> 状态：W1–W5 已实现；本地质量与桌面验收完成，环境缺项如下；W6 交付与发布入口见 §8。
> 需求唯一入口：[PRD 6.1.1](prd_6_1_1.md)。本计划负责顺序、交付与验收，不复制需求。

> 2026-10-16 补充：0.1.6 已公开发布。用户要求继续提升设置体验，并增加管理员启动后自动以普通权限运行。新增范围见 §9 和[设计说明](design_0_1_6_settings.md)，首轮原生实现已在当前会话部署验证，记录及缺项见 §10。已发布 tag 保持不变，后续公开交付使用新的补丁版本。

## 1. 版本目标与边界

用户能通过鼠标或键盘修改设置，辨认当前生效值、来源及重启要求；保存失败有明确反馈并可重试。关闭任务栏后仍能打开设置；预览从关闭启动也能热开启。高 DPI、小工作区下所有操作可达。

本版不增加开始菜单按钮、主题编辑、热键重绑定、电源/IME 状态、通知中心或文件桌面。任务栏大拆分、全局可访问性、全桌面混合 DPI、小时级长跑与预览采样架构保留在 [后续清单](prd_5_1.md)，不沿用旧 0.2.0 草案的交付承诺。

上述为已发布范围。2026-10-16 用户新增白天/黑夜/自动主题、任务栏四边停靠和工业复古风，覆盖原先“不增加主题”的边界，新增实施范围见 §11；不包括任意颜色编辑器。

## 2. 基线事实与设计决定

| 代码事实（静态核对） | 本版决定 | 需求 |
|---|---|---|
| `settings_ui` 自绘行主要靠鼠标，键盘只有 Esc | 使用原生控件、焦点顺序与可滚动内容区 | S1/S2 |
| 固定 460×720 客户区，主屏居中，无设置 DPI 分支 | 触发屏工作区布局、DPI 测量、固定反馈页脚 | S2 |
| `config::update` 先改内存，`persist` 无结果，同步文件 IO | 明确状态模型；独立有界串行保存，返回带代号的结果 | S3/S4 |
| 读取失败当空文件，备份失败仍继续直写目标 | 读失败停止、备份成功后临时文件替换，失败可重试 | S4 |
| `show_taskbar` 启动决定创建，UI 却用新偏好禁用相关项 | 区分运行状态与下次启动偏好，保留重启生效 | S3 |
| 环境变量加载时覆盖，UI 仍能改内存 | 展示有效来源，环境控制项只读 | S3 |
| `hover_preview::install` 禁用时提前返回，开关只请求 refresh | UI 线程幂等初始化，关闭取消计时/释放位图 | S5 |
| 设置入口依赖任务栏，二次实例直接拒绝 | `--settings` 呼出已有实例；无实例时启动并显示 | S1 |

## 5. 风险与收敛规则

- 原生控件采用系统配色可能与任务栏深色不同：接受这一取舍，以可读、焦点与高对比度为先，不为换肤再建自绘控件系统。
- 保存是本版主要工程风险：先 W1/W2 固定状态和故障语义，再接 UI；不得只给当前 `persist()` 补一个成功提示。
- 文件替换的原子性、备份与失败路径需按实际 Windows 行为测试；未检测的任意外部编辑竞态不宣称已彻底解决。
- 设置入口与单实例握手必须限定同一用户会话及固定动作，不扩成远程命令通道。
- 预览仅修生命周期；若基线慢目标阻塞影响设置验收，记录复现并重新评估 FUT-07，不用异步保存掩盖截图阻塞。

## 10. 后续实现与验证（2026-10-16）

- 设置：分为任务栏/窗口行为两个内容组；去掉逐项重复来源，配置与关于改为可滚动、可选择复制的只读窗口；桌面管理默认折叠。普通按钮保留原生行为和 UIA，只绘制简洁表面；复选与单选仍用原生控件。真实截图见[首轮原生界面](images/settings_followup_0_1_6.png)。

- 实测提升入口：测试启动器确认为提升权限，`--settings` 经降权子进程转交原有普通权限实例，启动器退出码 0，实例 PID 保持不变、仍未提升，Shell 注册信息未变。此证据来自用户补充说明前的一次测试模拟；产品没有加入主动提权逻辑，此后不再主动发起 UAC 测试。

# prd_6_1_1 — 设置日常可用与反馈闭环

> 实施契约更新（0.1.12，已发布）：0.1.12：桌面管理区显示当前会话、下次登录、恢复依据三行状态，沿用接管与“恢复接管前设置”两项动作。确认默认取消；后台交接中禁用两项动作、允许隐藏设置，正常退出等待交接结束。结果按实际登记与宿主状态表达，不保证恢复当前会话或执行第三方命令。

> 索引：6.1.1 · 上位：[任务栏策略](prd_6_1.md) · 更新：2026-10-15。
> 当前规则以[设计规范](design.md)为准，适用 0.1.9；0.1.6 的实现过程见[历史计划](archive/plan_0_1_6.md)。检测提升权限后普通权限重启已经交付，不主动请求 UAC。

## 1. 问题与目标

0.1.5 的设置能用鼠标改值，但用户无法可靠判断修改是否保存、是否需要重启；固定自绘布局缺少完整键盘路径与 DPI 适配。预览关闭启动后再打开，还缺少窗口初始化。关闭任务栏并重启后，原设置入口也不可达。

本版交付一条完整路径：打开设置 → 理解当前值与来源 → 修改 → 得到生效和保存反馈 → 失败可重试 → 重启后核对。配置键、默认值与优先级仍只定义于 [上位 §6](prd_6_1.md#6-配置与持久化配置键唯一真值表)。

## 2. 信息架构与界面

0.1.19 开发调整：默认采用宽窗双列，左列外观/窗口行为，右列工具/更新/配置/桌面管理，减少日常滚动；窄工作区回退单列。页脚固定、焦点可见及现有操作语义保持。实施范围见[计划](plan_0_1_19.md)，下方旧示意保留原有控件与反馈关系。

采用原生 Win32 单选、复选、按钮和只读文本；内容区可滚动，页脚反馈固定可见。沿用现有设置项，不增加主题编辑器、快捷键编辑器或恢复全部默认值。原生控件优先使用系统配色与清晰焦点，不为深色效果牺牲文字、选中态和焦点可辨认性。

```text
┌ 设置 ───────────────────────────────────────┐
│ 任务栏                                      │
│ ☑ 显示任务栏（重启后生效）                   │
│   当前：显示；下次启动：显示                  │
│ ☑ 显示通知区域                              │
│   伴随模式由 Windows 管理应用通知图标         │
│ 窗口合并                                    │
│ ● 从不合并 ○ 放不下时合并 ○ 始终合并         │
│ 合并依据  ● 按应用 ○ 按进程                  │
│ 行为  ☐ 悬停显示缩略图预览                   │
│ 外观 / 快捷键 / 关于（只读，可滚动查看）      │
│ 桌面管理                                    │
│ [接管桌面（立即生效）] [还原系统桌面…]       │
├─────────────────────────────────────────────┤
│ 本次已生效，保存失败：文件不可写  [重试保存]  │
│ [关闭]                                      │
└─────────────────────────────────────────────┘
```

正常状态页脚为“更改自动保存”；提交期间为“本次已生效，正在保存…”，成功为“已生效并保存”。重启项使用“已保存，重启后生效”。有任何未保存项时，成功保存另一项不能覆盖失败提示；详情可以展开查看路径和系统错误，常驻文案使用白话。

接管/还原区与普通设置用标题和间距隔开；不作为默认按钮。原有确认、默认“否”、备份和回滚条件遵循 [外壳规格](prd_3_1.md)。设置保存或关闭操作不触发接管、还原或自动重启。

## 3. 输入、焦点与呼出入口（S1）

- 鼠标与键盘触发同一设置操作。Tab / Shift+Tab 顺序遍历可用控件；单选组占一个 Tab 位置，组内方向键选择；Space 切换复选，Enter/Space 激活有焦点的按钮。
- 标题和说明不占 Tab 位置；禁用项保留可见原因并跳过焦点。当前项变为禁用时，焦点移至下一可用项；滚动始终使焦点完整可见。
- Esc、标题栏关闭和“关闭”均隐藏并复用窗口。Enter 在普通设置上不会触发桌面管理动作；确认框取消后焦点回到原按钮。
- 首次呼出焦点落首个可用设置；重开优先恢复上次有效焦点。已显示但非前台时再次呼出应置前；不因后台点击误隐藏。
- 增加 `--settings`：已有实例时请求同一用户会话内的实例显示设置；无实例时正常启动并显示设置，不创建第二个任务栏实例。任务栏关闭时仍可通过 Win+R 运行完整 exe 路径加 `--settings`；该路径不依赖本程序的 Win+R 注册成功。
- 请求使用专门的设置呼出消息，不复用外壳命令或任意字符串执行接口；启动尚未就绪时有界等待并显示明确失败，不静默成功。

## 4. 布局与 DPI（S2）

- 首次在触发设置的任务栏所属显示器工作区内居中；`--settings` 使用当前前台窗口所在显示器，失败回退主屏。重开时保证窗口仍位于可用工作区。
- 布局以 96 DPI 的逻辑尺寸计，按当前窗口 DPI 缩放；字体与控件测量决定行高，说明允许换行。默认宽度约 640 DIP，初始高度不超过工作区。
- 处理 DPI、窗口尺寸、显示器与工作区变化，重算内容及滚动范围；按 DPI 建立的字体在替换或销毁时释放。移屏后控件、命中区域与焦点位置一致。
- 小工作区优先保留内容视口、反馈、关闭按钮；通过滚动访问全部设置和桌面管理按钮。反馈长文本可换行或展开，不压住控件。测试 640×480 工作区和 100%/150%/200% 缩放组合。
- 物理混合 DPI 与拔插单列证据；模拟消息、几何测试不能代替实机覆盖。该项只承诺设置窗口，不宣称全桌面 DPI 验收完成。

## 5. 生效、来源与依赖（S3）

每项分别记录：本次有效值、用户偏好、配置来源、保存状态；重启项还记录下次启动值。UI 不以一个复选值推断所有状态。

| 设置 | 运行期行为 | 反馈与依赖 |
|---|---|---|
| 合并策略 / 依据 | 消息线程更新并经 hub 刷新任务栏 | 当前实际无任务栏时禁用；从不合并时依据禁用并说明原因 |
| 显示通知区域 | 立即更新布局；关闭时收起通知面板并清理其交互状态 | 明示当前伴随/替换模式；不影响 Explorer 通知宿主所有权 |
| 悬停预览 | 开关立即生效，生命周期见 §7 | 当前实际无任务栏时禁用 |
| 显示任务栏 | 只改下次启动偏好，不隐藏/创建现有任务栏 | 展示本次状态与下次启动值；待重启关闭不能提前禁用仍可用的设置 |
| 主题 / 唤出键 / 版本 | 只读，展示实际信息 | 主题手工修改后重启生效；不把配置字符串当成注册成功证据 |

有效启动覆盖对应的设置显示当前值和简短的“启动时固定”，禁止 UI 改写该项或其潜在偏好；主界面不展示环境变量名。来源详情仅在“配置与关于”中按需查看；无效覆盖不锁定设置。保持现有解析先后顺序，包括 `MINICON_TASKBAR` 对 `MINICON_NO_TASKBAR` 的覆盖，以及旧 `MINICON_GROUP_TASKS` 的兼容行为。文件和默认来源只作说明，不锁定设置。

任务栏运行状态来自启动/创建结果，不能只从偏好推断；创建失败应说明“本次任务栏不可用”。显示任务栏开关仍可修改下次偏好。0.1.6 不增加热键重绑定或全局热键诊断面板。

## 6. 保存状态与数据完整性（S4）

1. 普通即时项先应用于本次会话，保存异步完成；保存失败不撤销本次有效值。重启项保存失败时明确“下次启动偏好尚未保存”，不声称下次一定生效。
2. 设置写入使用独立、串行、有界的 IO worker；不共享可能被启动/路径查询阻塞的 Run worker，不访问任务栏状态锁或 HWND。worker 按请求代号更新共享状态，UI 每 100ms 定时读取快照；旧结果不能覆盖新值或新错误。
3. 快速修改按键合并为最新偏好，待保存键数有界；按串行顺序写入，最终文件与最后选择一致。队列不可用或 worker 失败时保留未保存标记并允许重试，不丢弃为成功。
4. 读取现有设置只有 NotFound 可视为空；访问失败、非法编码、路径是目录等均中止写入并保留原文件。保留非目标行、注释与未知键；沿用目标键更新规则，不顺手重写手工配置。
5. 对已存在文件先成功备份旧字节到 `.bak`，再同目录写临时文件、刷新并替换目标；备份、写入或替换失败均返回明确阶段与错误。首次创建使用不覆盖意外出现文件的路径。禁止先截断原文件再尝试写入；临时文件由写入操作负责清理。
6. 写入前重读并合并最新文件；检测读取后目标发生变化则中止并提示重试，不覆盖已检测到的外部编辑。临时文件替换前后边界须专测；本版不承诺与任意不合作编辑器跨进程事务互斥。
7. “重试保存”重试全部未保存键的最新偏好，即使值本次未变也要重试。关闭重开保留未保存状态；退出不无限阻塞，退出时仍有失败需提示，允许返回设置或明确放弃未保存修改；隐藏设置不会放弃。

## 7. 悬停预览生命周期（S5）

关闭状态启动后，在设置中开启也能创建/准备预览窗口；初始化在 UI 消息线程完成，可重复调用而不重复注册或分配。初始化失败恢复关闭状态、显示原因，不保存成“成功开启”。

关闭立即隐藏当前预览，取消其待显示计时器、清空目标并释放持有的位图；后续刷新不得重新显示。再次开启可正常工作。目标退出、设置窗口隐藏和程序退出时各资源有明确归属，100 次开关不应持续增长句柄/GDI。

该切片修复开关与清理；同步 PrintWindow 的重采样和慢目标架构留在 [FUT-07](prd_5_1.md)。本版不增加动态实时缩略图承诺，也不扩大截图调用位置。

## 8. 完成定义

S1–S5 全部实现，版本计划的自动化检查与实际桌面场景通过，并逐项登记证据、未覆盖环境和资源采样。新增控件应具备原生名称、角色、选中/禁用状态；设置窗口用键盘与屏幕阅读器检查，不把原生控件存在当成验收完成。全局自绘任务栏可访问性仍单独排期。

# 0.1.8 产品设计讨论稿

状态：讨论中，未开始功能实现。基线为已发布的 [v0.1.7](https://github.com/partnernetsoftware/minicon-winmgr/releases/tag/v0.1.7)。用户对当前设置暂基本接受；本轮保留紧凑、克制的暖色视觉方向。

## 建议主线：日常操作的确定性

优先把窗口切换、运行命令和修改设置这三条路径磨顺。以下是待讨论的设计候选，不代表已经发现对应缺陷，也不作为开发承诺。

| 顺序 | 用户场景 | 设计候选 | 完成标准 |
|---|---|---|---|
| P1 | 窗口很多，在横栏和竖栏之间切换 | 统一悬停、键盘焦点、当前窗口与分组状态；长标题/溢出优先保证可辨认，避免增加常驻按钮 | 四边均能区分当前/选中/悬停；鼠标与键盘完成同一任务，切换不抢走当前应用焦点 |
| P2 | 在 Run 中找回命令或打开路径 | 优化历史/路径候选的信息层级、选中与执行反馈；核查中英文文案和长路径显示 | 能区分候选来源；采用候选与执行动作明确；失败保留输入并给出可操作反馈 |
| P3 | 调整设置后确认是否生效 | 核查即时生效、下次启动、环境只读与保存状态的表达；继续调整对齐和焦点细节 | 默认窗口无需滚动即可完成日常设置；较窄窗口无重叠，焦点项可见；说明随状态出现 |

先按真实使用反馈选择一个切片，补充前后行为、草图与验证方法，再进入实现。推荐先做 P1，设置保留小幅修整。

## 保持的边界

- 设置仍是唯一配置入口，不恢复已退役的开始菜单或窗口列表按钮。
- English 默认，中文完整支持；明暗/自动主题与四边位置沿用，不另起视觉体系。
- 不因方便启动而主动申请 UAC；已提升时降权的规则沿用。
- 当前讨论不加入桌面文件浏览、拖放、第二套启动器或大规模架构改造。
- 内存构成与长期走势仍属 FUT-08，暂列 0.1.10 候选；短时资源数据不能代替该专项。

## 讨论焦点与验证

优先确认：当前更影响日常使用的是任务栏识别/切换、Run 的候选体验，还是设置的状态表达。每个切片开发期只跑相关层；准备下一次发布时执行完整 release 层。物理多屏/混合 DPI、屏幕阅读器和长跑需要单独环境，不把计划写成已覆盖。

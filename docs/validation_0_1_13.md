## 问题与修复

管理员启动有两个连续错误。进程枚举传入 Vec 容器的 24 字节，只返回前六个系统进程，找不到普通用户进程；修正为实际元素缓冲区大小，满缓冲区时有界扩容。找到普通令牌后，复制句柄又缺少默认安全属性与会话初始化的访问权，导致进程创建返回 0x80070005，备用 API 返回 0x80070522。

两条令牌复制路径现统一保留 QUERY、DUPLICATE、ASSIGN_PRIMARY、ADJUST_DEFAULT、ADJUST_SESSIONID 访问权。这些是复制句柄的访问权，不是启用普通令牌的管理员特权；同账户、同会话、普通权限校验，以及挂起子进程校验后再恢复执行的约束保持有效。

更新继续保留安装路径和文件名。配置详情增加实际 exe 路径、编译版本和权限，明确旧文件名中的版本号不能代表程序版本；不静默改名或改动登录外壳登记。

## 真实管理员入口与访问权对照

用户从任务管理器勾选管理员权限启动诊断程序。诊断原样编入当前 privilege.rs，并调用实际 normalize：管理员父进程为 High / Full，校验后重启的普通子进程为 Medium / Limited，普通子进程启动隐藏控制台成功，退出码为零，预期输出标记核对通过。父子报告按子进程 ID 关联；原始报告留在忽略目录。

相同账户/会话的普通令牌上，真实 CreateProcessWithTokenW 对照如下。每个成功案例都检查子进程身份及普通权限，并等待控制台退出，未把单纯获得句柄记为成功。

| 复制句柄访问权 | 使用 profile | 不使用 profile |
|---|---|---|
| QUERY / DUPLICATE / ASSIGN_PRIMARY | 拒绝访问 | 拒绝访问 |
| 以上加 ADJUST_DEFAULT | 拒绝访问 | 拒绝访问 |
| 以上基础项加 ADJUST_SESSIONID | 拒绝访问 | 拒绝访问 |
| 基础项同时加 DEFAULT / SESSIONID | 普通控制台退出 0 | 普通控制台退出 0 |
| 上一项再加 IMPERSONATE | 普通控制台退出 0 | 普通控制台退出 0 |

实际修复使用已验证成功的 DEFAULT / SESSIONID 组合，保留 LOGON_WITH_PROFILE；不额外请求 IMPERSONATE 或 ALL_ACCESS，不执行 runas，不依赖保存凭据。此项证明启动权限模块的真实管理员自重启链路；正式 exe 的普通入口桌面行为按下方同文件检查单独验收，不混称为正式 exe 的人工管理员 GUI 走查。

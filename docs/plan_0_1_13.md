# 0.1.13 计划草案：任务栏响应性与工作区恢复

> 2026-10-18 收口调整：本页仅保留为可能的维护改进，不再默认排期。仅当实际使用问题或缺陷需要时选取最小完整修复；不因版本编号存在就自动实施全部切片。

状态：**顺延设计，待讨论，尚未实施**。更新：2026-10-17。承接 [0.1.12](plan_0_1_12.md)；证据：[审阅 C04/C05/C06](review_0_1_12.md)。版本顺序为建议，实际启动前需核对前版交付与代码现状。

## 1. 目标与依赖

消除没有 UI 消费方的跨进程采样，减少未变快捷启动项的重复读取/图标提取，并让工作区恢复记录具有明确会话归属。本版不重新定义通知图标和窗口任务的产品交互。

前提：继承 0.1.12 的检查基线、必要能力判定和通知宿主转换；先复核 0.1.12 是否已顺带消除某条旧路径，不重复开发。当前没有实际慢盘/卡顿时长证据，不预先承诺优化百分比。

## 2. 切片与最小设计

13-02 先保持现有 pin 文件位置、格式、上限与显式路径覆盖，不同时迁移数据。区分任务刷新、文件内容变化和图标来源变化；缓存不能变成“只要路径相同永不刷新”。数量/字节上限、请求合并和退出策略需在实现前明确，不能为每次超时新建线程。

13-03 的旧无身份记录不能跨用户静默迁移。需要说明哪些信息足以证明归属；无法证明时保留原件并记录未恢复原因。无 broker 的非主屏工作区能力若需扩展，应另行立项，不能用记录迁移宣称多屏工作区已支持。

## 3. 验证与停止范围

先用故障 fixture 验证慢宿主/慢文件、快照失效、owned 图标寿命与两个身份的恢复隔离，再做准确候选的完整功能回归及短轮次资源对照。测量包含操作规模、构建、实际等待与静置回收，不能把减少消息数等同于固定内存收益。

不在本版修改 Run 的 Enter/Tab 规则，不迁移 pin/recents 文件，不重写 Alt+Space/旧菜单，不新增真实电源/IME 图标。混合 DPI/热插拔需真实设备另验，不能以模拟恢复记录替代。

## 4. 交付与后续

完成标志：三个切片各有失败回归和真实路径验证，现有功能完整回归通过，明确保留的环境限制。实际风险过高时可拆小版本，但不得拆出无法安全恢复的半份工作区迁移。

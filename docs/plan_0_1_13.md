# 0.1.13：管理员启动修复与运行路径说明

状态：实施中，尚未公开发布。更新：2026-10-19。

用户反馈：更新后进程路径令人困惑；从任务管理器勾选管理员权限启动时，出现 unable to start as standard user。

## 修复范围

- 修正 EnumProcesses 缓冲区长度：原代码传 Vec 容器大小，只能读取前几个系统进程，导致普通令牌备用路径不可用。按元素缓冲区大小枚举，满缓冲区时有界扩容。
- 保持同账户、同会话、真实普通权限的令牌验证与挂起子进程检查。不能用受限 Full 令牌替代，也不能在降权失败后继续以管理员运行。
- 配置详情同时展示编译版本、权限和实际程序路径，说明更新保留安装路径及文件名。文件名中的旧版本号不能用来判断运行版本；不自动改名，以免破坏现有启动入口。
- 保留可诊断的数值错误码，避免字符串隐私过滤掩盖令牌复制失败原因。

## 验证与交付门槛

1. 原生回归覆盖当前进程枚举、普通令牌复制与身份保持；语言和并行/串行单元矩阵、fmt、严格 Clippy 通过。
2. 从真实管理员入口验证自重启为普通权限，普通子进程可正常启动；普通入口不能重复自重启。普通入口测试不能代替管理员入口证明。
3. 对准确 CI 候选执行既有桌面、设置、更新和历史行为回归；保留用户原有实例路径并在结束时恢复。
4. 公开 Release 附件与已验收 CI 候选逐字节一致，公开发布后使用真实 .12 更新器完成 .13 交接，确认安装路径保持、实际版本和就绪回执。
5. 合并 main、公开发布和公开更新验证完成后，才能将本页标记完成。

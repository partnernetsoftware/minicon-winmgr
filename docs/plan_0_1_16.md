# 0.1.16 计划：Tskmgr 我的任务

状态：用户已授权开发并公开发布，尚未实现；前置 .15 已公开交付。更新：2026-10-19。需求唯一来源：[工具 PRD](prd_7_1.md)。

## 1. 目标与依赖

用户能从 Winmgr 的窗口找到对应进程，也能独立打开 Tskmgr 管理自己的任务。普通权限优先，先把列表、定位与操作反馈做可靠。

建议在 [0.1.15](plan_0_1_15.md)公开并完成真实旧版更新后进入本阶段。版本号指 Winmgr 集成里程碑，Tskmgr 首发版本号另定，不预设它也叫 0.1.16。

## 2. 任务树

```text
0.1.16 我的任务
├── A 工具运行边界
│   ├── [ ] 独立可执行目标；外壳与工具角色、实例隔离
│   ├── [ ] 明确同仓组织、产物定位与更新/回滚契约
│   ├── [ ] 仅抽取需要共享的主题、控件与查询能力
│   └── [ ] 查询/动作与 GUI 分离，Windows 适配边界及结构化结果
├── B 进程视图
│   ├── [ ] 当前用户/会话归属、身份未知和不可访问反馈
│   ├── [ ] 应用/进程关系，搜索与稳定排序
│   └── [ ] CPU、内存、路径与命令行的来源和刷新边界
├── C 日常操作
│   ├── [ ] 切换窗口、正常关闭、明确确认的结束进程
│   ├── [ ] 进程身份复核、退出/复用与部分信息不可用处理
│   └── [ ] 打开位置、复制信息、权限不足反馈
├── D 基础网络视图
│   ├── [ ] TCP/UDP 端点与进程关联；准确区分状态和未知值
│   └── [ ] 刷新开销、短连接与权限边界验证
├── E Winmgr 集成
│   ├── [ ] 工具统一入口与窗口对应进程定位
│   └── [ ] 缺失/不兼容/启动失败反馈，保留系统 Task Manager 入口
└── F 准确候选与公开交付
    ├── [ ] 独立启动、原生键盘、中英、DPI 与正常退出
    ├── [ ] 空闲/压力采样、挂起目标、PID 复用等实际验证
    └── [ ] 多产物版本与摘要、更新失败恢复及公开更新闭环
```

跨平台与未来 computer-use / mind-use 的架构原则见[基础服务 PRD](prd_7_2.md)。本期落实内部边界和无 GUI 的核心验证，不交付 macOS/Linux、通用 harness 或对外服务端。

## 3. 不纳入本阶段

管理员管理、进程树批量结束、进程实时网络速率、断开/阻断联网和防火墙写入进入后续设计；不建设插件平台、不安装服务或驱动、不新增 Sysmgr 主界面。权限不足时给出限制，不能为完成列表而提权整个外壳。

## 4. 完成条件与拆分规则

任务树按准确候选验证通过，独立工具和 Winmgr 集成均可用，外壳生命周期不受工具退出影响。多 exe 更新交付方案必须在开发前确定；当前单 exe 更新器不视为现成支持。

如果打包契约或基础网络视图使首期过大，优先交付可靠的进程管理；未完成项明确修改本计划并移交 [0.1.17](plan_0_1_17.md)，不能发布时仍声称已覆盖。UAC 管理入口在下一阶段具备能力后才展示。

## 测试范围的当前约定

按[风险选择规则](testing.md#当前规则2026-10-20)执行：只为本版变化及依赖边界收集必要证据，复用未改动能力的历史结果；不默认全套桌面回归或重复语言/并发矩阵。准确候选、权限/目标身份、失败恢复及真实公开交付仍须核实；通过项数量不作为质量指标。

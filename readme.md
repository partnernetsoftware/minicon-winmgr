# minicon-winmgr

**Less friction. More focus.**
**少些打断，多些专注。**

Your desktop should help you get things done.
桌面卡顿、入口繁杂、功能越堆越多——你只想安心把手头的事做完。

A lightweight Windows desktop shell, focused on stability and everyday simplicity.
winmgr 是一款轻量 Windows 桌面外壳，目标是让每天使用的桌面更稳定、更简单。

- **稳定为先 · Dependability first**：把可靠常驻放在第一位，减少桌面对工作的打断。
- **轻量少负担 · A lighter footprint**：关注内存占用，让桌面为你的工作留出更多空间。
- **简约按需 · Only what you need**：常用操作直接可达，可选功能按需开启。
